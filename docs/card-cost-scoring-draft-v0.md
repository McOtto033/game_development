# カードコスト点数モデル 叩き台v1

## 目的

カードのコスト、性能、レアリティの納得感を作るための暫定的な点数モデルを定義する。

この点数は最終的な強さを自動決定するものではない。新カード作成時の初期値、既存カードとの差分確認、総当たり結果と乖離したカードの異常検知に使う。

現行プロトタイプでは、係数の正本を `prototype/app.js` の `SCORING_RULES`、カード別の自動採点結果を `CARD_SCORE_INDEX` に置く。この文書は設計思想と係数の意味を説明するためのメモであり、実装と食い違った場合は実装側を優先して確認する。

## 基本方針

- ステータス点と効果点は分ける。
- プレイヤー向けの技名と、内部評価用の効果要素は分ける。
- 行動名そのものには点数を置かず、行動を構成する要素に点数を置く。
- ダメージ量、回復量、装甲量、バフ量はカードのAT/HP/AGなどから出る変数として扱う。
- AG操作、範囲攻撃、サーチ攻撃、α到達は重めの補正をかける。
- 条件が狭い、対策されやすい、対象なしが起きやすい効果は減点する。

## 盤面用語

プレイヤー向けの用語は、奥行きを「衛」、横方向のレーンを「列」と呼ぶ。

| 用語 | 意味 |
|---|---|
| 前衛 | 敵に最も近い奥行き |
| 中衛 | 前衛と後衛の間 |
| 後衛 | 自軍側に最も近い奥行き |
| 左列 | 自軍視点で左側の縦レーン |
| 中央列 | 自軍視点で中央の縦レーン |
| 右列 | 自軍視点で右側の縦レーン |
| 同列 | 左列/中央列/右列が同じこと |

旧称の「前列/中列/後列」は「前衛/中衛/後衛」に置き換える。旧称の「同段」は、基本的に「同列」と呼ぶ。

内部処理は、座標を正とする。マス番号は誤読や敵味方反転ミスの原因になりやすいため、正式な設計用語にはしない。

```text
自軍視点

後衛
中衛
前衛

左 中 右
```

```text
rank = 0: 前衛, 1: 中衛, 2: 後衛
lane = 0: 左列, 1: 中央列, 2: 右列
```

## 総点の式

```text
カード総点 =
  ステータス点
+ Σ(行動点 * 行動位置係数)
+ 必殺技評価点
+ 通常能力点
+ α特性点 * α採用率補正
+ 地形/タグ/コンボ補正
- 条件/弱点/対策可能性
```

行動点は、技名ではなく効果要素の合算で出す。

```text
行動点 =
  効果種別ベース
+ 対象面点
+ 対象選択点
+ 範囲形状点
+ 効果量点
+ タイミング点
+ 防御処理点
+ 複合行動補正
+ 危険タグ補正
- 条件減点
- 信頼性減点
```

必殺技は前衛/中衛/後衛の行動とは別枠で評価する。どのマスでも発動できるため位置係数は使わず、必要ターンに応じた必殺技到達係数を使って必殺技評価点を出す。

## ステータス点

ATは行動の効果量点で主に評価するため、ステータス点では二重計上しない。ステータス点は、カードが盤面に残り、行動機会を得るための素体価値として見る。

```text
ステータス点 = HP * 0.45 + AG * 0.35
```

AGは行動順に直結するが、AG強化能力や開幕AG付与は効果側でさらに評価する。

## 行動位置係数

後衛の行動ほど実行確率が高いと見なし、前衛、中衛、後衛の順に寄与率を上げる。

3つの行動は同時に全て使われるわけではないため、行動点を満額で3回足さない。カード総点に入れる時は、下記の行動寄与率を使う。

| 行動位置 | 行動寄与率 | 理由 |
|---|---:|---|
| 前衛行動 | 0.20 | 最終的には使いやすいが、被弾しやすく初動前に落ちるリスクがある |
| 中衛行動 | 0.26 | 前衛に守られやすく、初期配置での発動期待が高い |
| 後衛行動 | 0.32 | 最もアクセスされにくく、支援/遠隔行動の発動期待が高い |

ただし、後衛行動は前衛/中衛が崩れると別行動へ切り替わるため、長期戦で必ず高回数になるわけではない。実測で後衛が早く前進しがちな環境なら寄与率を下げる。

## 必殺技到達係数

必殺技は指定ターン数経過後、どのマスでも発動できる位置非依存の大技とする。膠着を崩す役割を持つため、通常行動より効果量を高くしてよい。ただし、発動までのターン数と短縮手段で評価する。

```text
必殺技評価点 =
  行動点として分解した効果点
* 必殺技到達係数
+ 必殺技短縮/連鎖リスク補正
- 必殺技不発リスク
```

| 必要ターン | 到達係数 | コメント |
|---|---:|---|
| 3T | 1.80 | 通常行動に近い頻度で届くため、かなり危険 |
| 4T | 1.40 | 早い大技枠。初期値にするとコスト対効果が高くなりやすい |
| 5T | 1.00 | 現行の標準。膠着崩しとして自然に届く |
| 6T | 0.80 | 長期戦/耐久構築向け。短縮デッキで価値が上がる |
| 7T | 0.65 | 専用構築向け。素撃ちは不発リスクが大きい |

必殺技短縮効果は、AG操作に近い危険度で見る。発動ターンを前倒しし、相手の準備ターンを奪うため。

| 効果 | 点数目安 | コメント |
|---|---:|---|
| 自身の必殺技を1T短縮 | +10〜16 | 大技の実発動率を上げる |
| 味方1体の必殺技を1T短縮 | +14〜22 | 対象選択できるなら高い |
| 味方全体の必殺技を1T短縮 | +28〜45 | 連鎖や同時発動が危険 |
| 発動後に再短縮 | +8〜20 | ループ形成に注意 |
| 敵の必殺技を遅延 | +12〜24 | 必殺技デッキへの回答 |

必殺技短縮を複数枚で重ねられる場合、点数だけでなく枚数制限や同一ターン制限で調整する。

## 対象面点

敵への攻撃/妨害は、到達しづらい奥のマスほど高く見る。

| 対象奥行き | 深度値 |
|---|---:|
| 敵前衛 | 0 |
| 敵中衛 | 1 |
| 敵後衛 | 2 |

```text
対象面生値 = 対象に取り得る各マスの深度値合計
攻撃/妨害の対象面点 = 対象面生値 * 2.0
支援/防御の対象面点 = 対象面生値 * 1.0
```

例:

| 対象範囲 | 生値 | 攻撃/妨害点 |
|---|---:|---:|
| 敵前衛全域 | 0*3 = 0 | 0 |
| 敵後衛単体 | 2 | 4 |
| 敵中後衛全域 | 1*3 + 2*3 = 9 | 18 |
| 敵左右列6マス | 0*2 + 1*2 + 2*2 = 6 | 12 |
| 敵全域9マス | 0*3 + 1*3 + 2*3 = 9 | 18 |

前衛全域攻撃は対象面点だけでは高くならない。これは、前衛へ届くこと自体は基準であり、強さは範囲形状点と総ダメージで評価するため。

## 範囲形状点

対象面点は「奥へ届く価値」、範囲形状点は「複数対象へ当たる価値」を見る。

| 範囲形状 | 点数目安 | コメント |
|---|---:|---|
| 単体 | 0 | 基準 |
| 最大2体 | +6 | 対象欠けを考慮 |
| 3マス範囲 | +12 | 前衛全域、同衛全域など |
| 4〜6マス範囲 | +18 | 中後衛全域、左右列など |
| 7〜9マス範囲 | +26 | 全体級。状態異常ならさらに警戒 |

実際に命中する期待対象数は別途、効果量点で掛ける。例えば3マス範囲でも、平均命中が2.1体ならダメージ量は2.1体分で見る。

## 対象選択点

| 対象選択 | 点数目安 | コメント |
|---|---:|---|
| 最前優先 | 0 | 基準 |
| 同列固定 | 0 | 配置で読める |
| 後衛優先 | +8 | 支援役へ届きやすい |
| 中後衛限定 | +8 | 前衛を迂回する |
| 最低HP優先 | +10〜14 | 撃破期待値が高い |
| 最高AT/AG優先 | +10〜16 | キーカード処理に向く |
| α優先 | +16〜24 | 勝利条件に直結 |
| 負傷味方優先 | +4〜8 | 回復の無駄撃ちを減らす |
| ランダム | -4〜-10 | 不確実性。対象プールを狭められるなら減点を軽くする |

ランダムは常に悪ではない。高火力、広い対象面、デッキ構築で対象プールを狭められる設計があるなら、リスクリターンとして成立する。

## 複合行動補正

1回の行動で複数の役割をこなす技は、各効果を分解して点数化したうえで補正する。

| 複合の性質 | 点数目安 | コメント |
|---|---:|---|
| 攻撃+防御 | +4〜10 | ダメージを止めつつ勝利へ進む |
| 攻撃+回復 | +4〜10 | 回復役の手番損を減らす |
| 強化+攻撃 | +6〜12 | 先に強化して後続攻撃へつなぐなら高い |
| 回復+回復 | 0〜+4 | 1回の大回復で表現できるなら低い |
| 効果が散りすぎる | -4〜-12 | ログ負荷、読みづらさ、対策不能感を考慮 |

## 危険補正タグ

| タグ | 加点目安 | 内容 |
|---|---:|---|
| tempo | +10〜30 | AG操作、開幕行動、未行動順変更 |
| wide | +10〜35 | 複数対象攻撃、前衛崩壊を早める |
| search | +10〜30 | 低HP狙い、後衛狙い、中後衛狙い |
| bypass | +10〜25 | 前衛を迂回する |
| lethal | +15〜40 | α優先、露出α特攻 |
| lock | +10〜35 | 回復/装甲/バリアで膠着を作る |
| opener | +10〜35 | 開戦時に盤面を大きく変える |

危険補正は常に満額で足すものではない。総当たりで突出した勝率、短すぎる平均勝利ターン、対策デッキの少なさが見えた時に上げる。

カード単体のコスト評価では、デッキ内シナジーそのものには原則として点を足さない。同じコスト内で勝ち筋を最大化することが構築の面白さであり、そこへ直接課税すると発見の報酬を削るためである。

ただし、カード自身が持つ効果要素と、そのカード内で自己完結する最大値は通常通り評価する。例えば「味方全体にAG+6」「同分類の味方にAT+3」「毒を付与する範囲攻撃」は、それぞれAG操作、AT強化、毒/範囲攻撃として点数化する。さらに「後衛時だけ自分の掃射が強くなる」「α指定時に自分の範囲攻撃を開戦時に撃つ」「自分のα特性と自分の通常能力が同じ行動へ重なる」ものは、他カードとのコンボではなくカード単体の自己完結最大値として課税する。

一方で「このカードと別カードを組み合わせると強い」という事実だけでは加点しない。例えば、他カードのAG強化で先に範囲攻撃を撃てる、他カードの防御低下後に掃射する、毒付与役と毒参照アタッカーを並べる、といったデッキ内コンボはカード単体点へ直接足さない。

## コンセプト最大値ベースの評価

機械的に全ステータス、前衛/中衛/後衛行動、必殺技、特性を足すだけでは、カードの想定運用と違う点が混ざりやすい。今後のカード単体評価では、まずそのカードのコンセプトを置き、その使い方が成立した時の盤面影響を主評価にする。

例:

| カードの型 | コンセプト最大値として見るもの | 補助的に見るもの |
|---|---|---|
| 後衛範囲砲 | 後衛に置いた時の範囲打点、開幕/必殺技との自己完結重なり | 前衛に出た時の最低限の行動 |
| 高速一点突破 | 先に動いて倒せる対象、低HP/後衛/αへの到達性 | 長期戦の必殺技 |
| 耐久支援 | 何ターン分の生存を作り、その間に主軸へ何回行動を渡すか | 単発の回復量 |
| 妨害役 | 相手の遂行ターンを何ターン遅らせるか | 自前の小ダメージ |
| α専用核 | α指定時にだけ成立する開幕/常在/露出後性能 | 通常採用時の汎用性 |

通常点は「通常採用でそのコンセプトを使った時の最大値」、α点は「α指定でそのコンセプトを使った時の最大値」を基準にする。前衛/中衛/後衛の全行動を漏れなく評価する機械的点数は、設計漏れ検出とUI説明用の補助値として扱う。

役割ごとに点数帯の読み方も変える。攻撃/範囲/高速カードは短い決着ターンを作るため、同じ点でも重く見る。耐久/回復カードは単体点が低くても、実戦で主軸行動回数を増やすならデッキ検証側で評価する。

## 現行仮行動の分解

ここにある行動名は仮IDであり、正式な技名ではない。カード固有技は、下記のように効果要素へ分解して評価する。

| 仮ID | 現効果 | 分解 |
|---|---|---|
| slash | 最前の敵1体にATダメージ | 攻撃 + 敵前衛/最前優先 + 単体 + AT依存ダメージ |
| pierce | 同列の前から2体にAT-5/AT-10、守られたαは軽減 | 攻撃 + 同列前方 + 最大2体 + 減衰ダメージ + α到達軽 |
| sweep | 敵前衛全体にAT-10 | 攻撃 + 敵前衛全域 + 3マス範囲 + 範囲ダメージ + wide |
| guard | 自分と同列前方に装甲、同列最前の敵へ装甲無視小攻撃 | 装甲 + 自分/同列前方 + 攻撃 + 同列最前 + 装甲無視 + 複合 |
| rally | 味方前衛にAT+3/2T | AT強化 + 味方前衛全域 + 複数対象 + 持続 |
| heal | 最傷味方を回復し、同列最前の敵へ小攻撃 | 回復 + 負傷味方優先 + 攻撃 + 同列最前 + 複合 |
| lineHeal | 同列の傷ついた味方全体を小回復 | 回復 + 味方同列 + 負傷味方限定 + 複数回復 |
| generalWard | 味方αに装甲+小回復 | 装甲 + 回復 + 味方α固定 + lethal防 |
| snipe | 後衛を狙う。守られたαには軽減 | 攻撃 + 敵後衛優先 + 単体 + 後衛アクセス + α到達軽減 |

## レアリティ補正の考え方

レアリティは、同コスト内の単純上位互換ではなく、以下に点数を置く。

| レアリティ価値 | 加点目安 | 説明 |
|---|---:|---|
| 独自性 | +10〜30 | 代替しづらい対象アクセスや状態 |
| コンボ上限 | +10〜35 | 専用構築で大きく伸びる |
| 汎用性 | +10〜25 | 多くのデッキに入る |
| 構築制約 | -10〜30 | 地形/タグ/配置依存で減点 |
| 対策可能性 | -10〜25 | 明確な回答札があるなら減点 |

低レアはコスト効率と役割明瞭性を高くし、高レアは独自性と上限を高くする。高レアを同コストの完全上位互換にしない。

## 運用手順

1. 新カードのステータス点を出す。
2. 各衛の行動を効果要素に分解する。
3. 行動点に行動位置係数をかける。
4. 通常能力点を、追加効果量と発動率で出す。
5. α特性点にα採用率補正をかけて足す。
6. AG、範囲、サーチ、α到達、膠着の危険補正を見る。
7. 仮コストへ割り当てる。
8. 総当たりと代表リプレイで、点数と実測がズレた要素を補正する。

## 現時点の警戒対象

- AG強化: 未行動順に即時反映されるなら、効果量点だけでなくtempo補正を必ず足す。
- 範囲攻撃: ATが低く見えても総ダメージが膨らむため、期待命中数とwide補正を必ず使う。
- サーチ攻撃: 支援役処理と撃破確定に直結するため、対象選択点とsearch補正を重く見る。
- 後衛行動: 実行確率が高いため、行動位置係数を前衛より高くする。
- 開幕系α特性: 1ターン目の脱落数に直結するため、opener補正を必ず加える。
- 回復/装甲の複合: 点数が低く見えてもミラー膠着を作るならlock補正を加える。
- 毒: 耐久型の決着手段になるため、回復封じ/防御低下と重ねた時の総ダメージを確認する。
- 防御低下: 単体では控えめでも、範囲攻撃や必殺技と組むと実測が跳ねやすい。
