作成日: 2026-08-12  
対象: `prototype/app.js`, `prototype/index.html`

## 目的

プロトタイプでプレイヤーに見える、または仕様一覧/カード詳細/生成候補で見える可能性がある語を列挙する。日本語として変なもの、世界観「異世界生態系SF」に合わないものは指摘し、すぐ直せるものはプロトタイプへ反映する。

## 監査メモ

| 対象 | 判定 | 理由/対応 |
|---|---|---|
| 行動名 `斬撃` / `貫通` / `掃射` / `狙撃` | 要改名 | 汎用戦闘語・兵器語に寄っており、生物ごとの行動としては硬い。本実装ではカード固有技へ分解する。 |
| 行動名 `守護` / `鼓舞` / `祈祷` / `献身` / `指揮` / `破陣` | 要改名 | 人型、軍事、宗教のニュアンスが残る。プロトタイプでは共通行動IDとして残し、本実装時に `殻壁展開`、`前衛活性`、`再生胞子`、`α護膜`、`同調信号`、`露出捕食` などへ寄せる。 |
| `スカイレイ` | 要確認 | 鳥類だが `レイ` が魚類/光線の両方を連想する。図鑑上は飛行種なので、鳥類として残すなら翼/滑空を連想する名前へ寄せる余地あり。 |
| `クロノアンモナイト` | 要確認 | アンモナイトは魚類ではない。分類追加が許されるなら `軟体類` を検討。分類を増やさないなら、魚類枠の古代水棲カードとして仮置き。 |
| `アイアンシダ` | 注意 | シダは植物で、分類は菌類。図鑑文で「植物状菌類」と説明しているため仮運用は可能だが、菌類らしさを強めるなら改名候補。 |
| 英語複合名全般 | 注意 | アーマークラブ、サンダーイール、ブリンクフォックス、ヴェノムモス、ミラータートルなどは読みやすいが、やや汎用モンスター名寄り。正式カードでは観測名/種名らしい日本語混じりへ寄せる。 |
| `スケーリング` / `ロック` | 注意 | 内部設計語としては可。UIに強く出すなら `成長`、`妨害固定` など日本語化を検討。 |

## 次の修正方針

1. 行動IDを共通技からカード固有技へ移す時に、行動名を一括で生物由来へ改名する。
2. `クロノアンモナイト` のために `軟体類` を分類へ追加するか、カード名を魚類寄りに変えるか決める。
3. 英語複合名は、初期カードプール確定時に「観測名」「俗称」「種名」のどれかへ統一する。
4. 生成候補名は開発用としては現状維持。プレイヤー向けに出すなら、勝ち筋名を直接出しすぎない表示へ変える。
