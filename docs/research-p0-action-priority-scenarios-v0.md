# P0判断用 D4行動優先度 専用シナリオ検証 v0

## 目的

D4で採用した行動優先度ルールを、総当たり前に小さな固定シナリオで確認する。

この検証は本体戦闘エンジンの実装変更ではなく、D4ルールだけを切り出した研究用ミニリゾルバである。

対象スクリプト:

```text
scripts/research-action-priority-scenarios.js
```

実行コマンド:

```text
node --check scripts\research-action-priority-scenarios.js
node scripts\research-action-priority-scenarios.js
```

結果:

```text
D4 action-priority scenario results: 12/12 passed
```

## 検証したルール

| ID | シナリオ | 確認したこと | 結果 |
|---|---|---|---|
| S1 | 防御準備で致死回避 | 防御準備は同じ効果段の攻撃に間に合う | PASS |
| S2 | 単発回復はKO対象を復帰させない | 攻撃後にHP0の対象は回復対象外 | PASS |
| S3 | 生存者への単発回復 | 非致死ダメージ後の回復は通る | PASS |
| S4 | 回復封じは次段から | 同じ効果段の回復は通り、次の効果段の回復は止まる | PASS |
| S5 | 防御低下は次段から | 同じ効果段の攻撃には乗らず、次の効果段の攻撃から効く | PASS |
| S6 | KO後の行動保証 | HP0表示後でも、決定済み行動で生存味方を回復できる | PASS |
| S7 | 解除と同段付与 | 解除は既存状態だけを消し、同段で新規付与された状態は残る | PASS |
| S8 | 持続状態付与の内部順 | 被ダメージ修飾 > 回復制御 > 継続ダメージ > 継続回復 の順で正規化 | PASS |
| S9 | ステータス/ゲージ正規化 | AT/AGは乗除 > 加減、ゲージ増減は同段合算 | PASS |
| S10 | 防御反応 | 接触毒/反射殻の構えは同段被弾に間に合う | PASS |
| S11 | AG変更は現在バッチへ割り込まない | AG上昇後も現在選択済みバッチを再選択しない | PASS |
| S12 | 必殺技ゲージ充填は現在行動を置換しない | ゲージが満タンになっても現在の通常行動は維持される | PASS |

## 解釈

専用シナリオ上では、D4採用ルールは意図通りに働く。

特に重要な確認点:

- 防御と回復の役割差は出ている。
  - 防御は同段攻撃に間に合い、致死を防げる。
  - 回復は攻撃後に入り、HP0からの復帰にはならない。
- 回復封じ、防御低下などの状態付与は、同じ効果段には割り込まない。
- 1段目状態付与、2段目攻撃/回復というカード内コンボは成立する。
- 段末解除は、同段新規付与まで巻き込まない。
- AG/必殺技ゲージ変更は、現在選択済みの同AGバッチや現在行動を変えない。

## 検証外

以下はこの専用シナリオでは判断しない。

- 毒や継続回復など、状態ごとのスタック可否。
- 反射/接触効果が致死被弾時にも発動するか。
- 行動制御の実効仕様。行動制御は順序枠だけ置き、初期実装では未使用。
- 本体プロトタイプの総当たり結果への影響。

この後、D4採用ルールを検証装置の実験戦闘へ反映し、標準総当たりを実行した。
