# カード案バックログ

作成日: 2026-08-12  
種別: 後続実装候補のメモ

## 目的

思いついたカード案を書き残し、カードを大量に追加するフェーズが来たら、この中から仕様化・コスト評価・プロトタイプ実装へ移す。

このメモは完成仕様ではない。短い着想、未調整の強効果、名前だけの案も残してよい。実装前に [カード設計スキーマ v0](../docs/card-design-schema-v0.md)、[初期カードプール v0](../docs/initial-card-pool-v0.md)、[カード能力・行動・状態異常案メモ](card-mechanics-ideas.md) と照合する。

## 使い方

- まずは `未整理案` に一言で追加する。
- 実装が近づいたら `仕様化候補` に移し、分類、特性、役割、配置別行動を埋める。
- 強すぎそうな案ほど消さずに残し、条件、必要ターン、対象範囲、コスト、対策余地で調整できるかを見る。
- 既存カードの上位互換になりそうな案は、差別化メモか危険フラグを必ず書く。
- UIに出す説明と、内部だけで持つ勝ち筋/対策メモは分ける。

## 状態

| 状態 | 意味 |
|---|---|
| `idea` | 名前や能力だけの着想 |
| `candidate` | 役割と行動の方向が見えている |
| `spec-ready` | スキーマに沿って実装できる |
| `hold` | 面白いが、処理順やバランスの都合で後回し |
| `rejected` | 採用しない。理由確認用に残す |

### 候補一覧

#### 電気ウナギ強放電モデル

```text
仮ID: highVoltageEel
カード名: 未定。既存サンダーイールのリワーク、または別個体として実装する。
状態: candidate
分類: 魚類
特性: 水棲 / 発電
役割: 攻撃 / 妨害
想定コスト/αコスト: 4/6または5/7
ステータス方向: 中HP / 中AT / 中AG。前衛で動けるが、自己反動と味方巻き込みを背負う。

前衛行動:
  放電。対象は自分を含む敵味方の前衛6マス。
  自分以外にAT×1.0ダメージ、自身にAT×0.2ダメージ。
  追加効果として、自分以外の対象にAG-10/1T。
  属性概念を導入する場合は電気属性攻撃。
中衛行動:
  未定。電位蓄積、同列AG弱体、または前衛補助のいずれか。
後衛行動:
  未定。発電系支援、自己AG強化、または低威力の電撃。
必殺技:
  未定。敵味方巻き込みを広げるより、敵前衛全体+AG弱体程度に抑える案が無難。
必殺技必要ターン: 未定
α特性:
  未定。反動軽減、電気属性強化、水棲/発電参照などが候補。

内部コンセプト:
  電気ウナギの強い放電をゲーム効果として再現する。敵前衛を削りつつAGテンポを落とすが、味方前衛と自身も巻き込む。
  既存のサンダーイールは現在AG支援カードなので、実装時は以下のどちらかを選ぶ。
  1. サンダーイールをこの強放電型へリワークする。
  2. サンダーイールは支援型として残し、別名の大型/高レア電気ウナギとして追加する。
想定シナジー:
  AGテンポ、前衛制圧、海地形、水棲/発電デッキ。装甲や回復で味方巻き込みを受ける構築とも相性がある。
想定対策:
  後衛狙い、先制撃破、前衛を薄くする配置、装甲/バリア、AG低下耐性。
危険フラグ:
  firstStrikeLock / aoeOverkill / hiddenComplexity
次に決めること:
  敵味方巻き込み攻撃のログ・検索メタデータ・点数評価をどう扱うか。
  自身へのAT×0.2反動に装甲や軽減を適用するか。
  AG-10/1Tを味方にも入れるか、敵だけにするか。現案では自分以外の敵味方全員。
  電気ナマズではなく電気ウナギ前提で、名前、図鑑テキスト、既存サンダーイールとの関係を決める。
```

## 実装前チェック

- 既存24枚のどれかの単純上位互換になっていないか。
- 勝ち筋は、一点突破、盤面制圧、α直接突破、エース遂行、継続ダメージ耐久、ロック/妨害制圧、反撃/受け崩しのどれへ接続するか。
- 構築エンジンは、分類統一、特性統一、地形、必殺技短縮、α支援、AGテンポ、装甲/回復、防御低下/回復封じ、スケーリング、条件バーストのどれか。
- 対策不能、極端な膠着、初動ロック、ミラー不安定を生まないか。
- 実装に新しい処理順が必要か。必要なら先にルール文書へ反映する。
- 検索用に `位置 × 効果要素 × 対象パターン` へ展開できるか。
