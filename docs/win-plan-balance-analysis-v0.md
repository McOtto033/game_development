## 甲殻菌糸

問題は、1枚のカードが突出しているというより、防御エンジンと毒エンジンが同時に成立している点。

- 平均軽減477.5、回復199.6、装甲433.9で、総耐久量が他デッキより一段高い。
- 毒13.1回、胞子砲複数回、前線固定が噛み合い、長引くほど勝つ。
- `α直接突破1` 相手にも100%。相手は6Tで544ダメージを出しているが、甲殻菌糸は588軽減+123回復で受け切り、敵αを毒と胞子砲で落とす。
- 腐蝕制圧とは向き補正で50%。腐蝕は防御低下9回程度を入れ、甲殻菌糸の軽減を突破できる唯一の既存モデルになっている。

分析上の異常値は「甲殻菌糸が耐久デッキなのに決着速度も十分高い」こと。耐久、回復、毒火力のどれかではなく、3要素の同時成立に課税が必要。

## α直接突破1

問題は、速度と壁処理の再現性が高すぎること。

- 平均4.0T、勝率91%。短期決着力が標準より高い。
- 壁3枚、到達3枚、露出後122という生成評価どおり、前衛処理とα到達が両方高い。
- ただし甲殻菌糸には0%。防御が厚い相手に対してはα到達前に毒/胞子砲で削り返される。
- 実態としては「高速・無防御・短期決着」の上振れ生成で、カード単体より生成デッキの攻撃密度が異常値。

次に見るべきは、α直接突破テンプレートの上限ではなく、5枚30コストで壁処理とα到達を両立しすぎていないか。

## 反撃/受け崩し

反撃は55%で、デッキコンセプトとしては成立したが、主勝ち筋というより相性補助に近い。

- 腐蝕制圧に200-0、盤面制圧1に200-0。範囲/前衛接触に強い。
- 甲殻菌糸に0-200、α直接突破1に0-200、疾走捕食に0-200。防御を貫く決着力や高速α処理には弱い。
- 接触毒/反射殻は平均3から4回程度で、過剰ロックではない。

ロック/妨害と同じく、主勝ち筋ではなく補助パッケージとして調整するのが妥当。

## 継続ダメージ耐久

勝率27%で弱い。毒量は足りているが、毒が効くまで盤面を維持できていない。

- 毒22.3回と状態付与量は高い。
- 回復240.5、軽減163.4はあるが、甲殻菌糸の軽減477.5とは差が大きい。
- αダメ80.3と決着効率が低い。毒を撒いてもαへ届く前に主軸が落ちる。
- 盤面制圧1には200-0で勝てるため、完全に弱いのではなく、高速α/高耐久エンジンへの回答が足りない。

必要なのは毒火力追加ではなく、序盤の前衛維持、毒対象の安定、または毒がαへ移るルート。

## 次の優先

1. 甲殻菌糸の耐久+毒の同時成立へ課税する。
   - 候補: `sporeTitan` の胞子砲/毒、`STANDARD_ARMOR_DURATION=2`、回復+装甲の重複、`firstFallHeal` の価値。
2. α直接突破1の生成上振れを分析する。
   - 候補: α直接突破テンプレートで「壁処理」と「α到達」を同じ大型カード群が兼ねすぎている。
3. 継続ダメージ耐久は毒量ではなく維持/到達不足を補う。
   - 候補: 毒対象の継続、αへの毒移行、前衛維持カード。
4. 反撃/ロックは主勝ち筋化しない。
   - 現状の反撃は補助勝ち筋として妥当な範囲。ロックは標準生成なしを維持。
