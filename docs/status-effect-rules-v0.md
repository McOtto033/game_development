## 実装範囲

`prototype/app.js` の `STATUS_EFFECTS` が状態の分類、標準期間、重複規則、解除マスク、実装有無の正本。D4の段末付与順に使う状態ファミリーもここから生成する。毒6ダメージ、防御低下の被ダメージ+4などの値は従来どおり。

| 状態 | 実装 | 重複と再付与 | 標準期間 | 解除マスク |
|---|---|---|---|---|
| 毒 | 使用中 | 1対象1枠、加算なし、期限は長い方 | 3T | all / weak / dot |
| 回復封じ | 使用中 | 1対象1枠、加算なし、期限は長い方 | 1T | all / weak / healControl |
| 防御低下 | 使用中 | 1対象1枠、加算なし、期限は長い方 | 1T | all / weak / damageTaken |
| 接触毒 | 使用中 | 従来の1枠上書きを維持 | 2T | all / buff |
| 反射殻 | 使用中 | 従来の1枠上書きを維持 | 2T | all / buff |
| 継続回復 | 未公開・未実装 | 将来は1枠で強い付与を優先 | 未定 | all / buff |
| 麻痺 | 未公開・未実装 | 行動制御の設計枠のみ | 未定 | all / weak / actionControl |
| バリア状態 | 未実装 | 独立した状態としては設計枠のみ | 未定 | all / defense |

装甲は別の `armorEffects` にあり、既存の装甲や貫通は引き続き動く。「バリア状態が未実装」は装甲機能の無効化を意味しない。`counters` は対策候補のメタデータであり、名前だけで解除や耐性を自動発生させない。

## 期間と帰属

- 状態の期限は `max(1, 付与ターン + duration - 1)`。期限のターンまで有効。次のターンでは無効になる。
- 毒はターン開始時に処理する。通常の行動でT1に3T付与した場合、T2とT3に各6ダメージを与え、T4には失効する。期間3Tは必ず3回のダメージを保証する値ではない。
- 毒/回復封じ/防御低下を再付与する際、既存の有効期限と新しい期限の長い方を採る。短い再付与で期限を縮めない。
- 新しい期限が同じか短い場合は、既存の付与元ID/陣営/期間レコードも維持。長く更新した場合は新しい付与元へ移す。期限切れの同キーのレコードは再付与時に除去する。
- 同期限の同時付与はD4の既存の正規順で先のものに帰属する。重複によるダメージ加算は起こさない。
- 未定義状態、`implemented: false` の状態、非正整数の期間、HP0の対象への付与は成立しない。成立しない状態付与をログや付与数へ計上しない。

## 解除と将来の継続回復

`clearStatusEffects(state, unit, masks)` は、指定したマスクの和集合に一致する有効な状態を解除し、解除したレコードを返す。重複マスクで複数回解除しない。未知マスクは一致せず、他の状態を消さない。`weak` は弱体全般、`buff` は強化消去。毒だけなら `dot` を使う。

この関数は明示的な効果から呼ぶための内部処理で、M1-01では解除カードや新しい段末操作を追加しない。装甲/ステータス操作のレコードは対象外。単発回復は毒を解除しない。

継続回復は `unlockPhase: depth`、`implemented: false` の予約定義。現在は付与も回復も発生しない。将来の実装では回復封じで回復量を0にしても期間は進み、戦闘不能は復活させない。強い付与と長い付与を合成する挙動は実装せず、具体的な強弱規則を判断台帳へ記録してから有効化する。
