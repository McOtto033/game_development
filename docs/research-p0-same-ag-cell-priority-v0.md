# P0判断用 同AGマス優先比較 v0

## 目的

ユーザー案に合わせ、同速勝負を以下の実ルール候補で検証する。

1. コストは同AGタイブレークに使わない。
2. 同速勝負は、まずマス優先で解く。
3. マス優先は、前中 > 前左 > 前右 > 中中 > 中左 > 中右 > 後中 > 後左 > 後右。
4. マスが同じならレアリティで解く。
5. AG、同じマス、同じレアリティが敵味方で揃った場合だけ、最大2体の同AGバッチにする。
6. 同AGバッチに入った行動は、HP0後でも発動保証する。
7. 同AGバッチ内の異なる行動は、暫定で 防御/準備 > 攻撃/妨害 > 回復 の優先度で処理する。

この文書は採用判断用の調査メモであり、本体戦闘エンジンの正本仕様はまだ変更していない。

## 調査スクリプト

`scripts/research-same-ag-cell-priority.js`

実行:

```sh
node scripts/research-same-ag-cell-priority.js
```

特定対面の短縮ログ:

```sh
node scripts/research-same-ag-cell-priority.js --pair-summary "生成: 盤面制圧2" "甲殻菌糸" 45
```

検証器の注意:

- 初回実装では、同時の `守護` / `祈祷` を片側から丸ごと順番処理していたため、甲殻菌糸ミラーが片側勝ちになる歪みが出た。
- 修正後は、現行エンジンと同じく `守護` は防御部分を双方処理してから反撃部分、`祈祷` は回復部分を双方処理してから攻撃部分を処理する。
- 修正後、甲殻菌糸ミラーは現行/候補とも80T引き分けに戻った。

## 代表対面

### 生成: 盤面制圧2 vs 甲殻菌糸

結果:

| ルール | 結果 | ターン |
|---|---|---:|
| 現行 | 生成: 盤面制圧2 勝利 | 4T |
| マス優先候補 | 甲殻菌糸 勝利 | 19T |

主因:

- 候補では、敵側 `レジンビートル` と `ミラータートル` の守護が、こちらの中衛/後衛攻撃より先に入りやすい。
- `ボルカノドレイク` の掃射や必殺が装甲/反射殻込みで受けられ、短期突破が失敗する。
- 終盤は `ミラータートル` が前中に残り、反射殻で `ボルカノドレイク` を削り切る。

読み:

- 中央/前衛の高リスク配置を同速優先で保証する、という設計思想には合う。
- 一方、守護/反射が強く働くため、長期化と耐久側の読み勝ちが増える。

### 生成: 盤面制圧1 vs 腐蝕制圧

結果:

| ルール | 結果 | ターン |
|---|---|---:|
| 現行 | 生成: 盤面制圧1 勝利 | 4T |
| マス優先候補 | 腐蝕制圧 勝利 | 4T |

主因:

- 候補では、同AG18の中で `ボルカノドレイク` の処理順がマス優先で変わる。
- 4Tに双方αが斬撃し合うが、同マス同レアバッチとして両方の行動が成立する。
- 結果としてこちらαも倒れ、相手勝利になる。

読み:

- 同AGバッチ内の行動保証により、先にHP0にした側だけが一方的に勝つ展開は減る。
- これはプレイヤー期待とミラー公平性には合うが、短期決着の一部は反転する。

### 疾走捕食 vs 生成: エース遂行1

結果:

| ルール | 結果 | ターン |
|---|---|---:|
| 現行 | 生成: エース遂行1 勝利 | 7T |
| マス優先候補 | 疾走捕食 勝利 | 7T |

主因:

- 候補では、敵側 `ミラータートル` の守護と `タイタンミセリウム` の攻撃順がマス優先で入れ替わる場面がある。
- 7T時点で `グラスマンティス` が生存し、追加の斬撃で敵αを倒し切る。

読み:

- マス優先は防御型だけでなく、高AGで前に出る攻撃側にも得になる。
- 「安全な後衛から強い行動をする」より、リスクある前方配置に実利を持たせる方向には合う。

## 判断材料

### 採用寄りの理由

- ユーザー意図の「被弾リスクが高いマスほど同速優先で補償する」に合う。
- 同AGバッチ対象が最大2体になり、広い2フェーズ案よりルールが説明しやすい。
- 完全ミラーの片側固定勝ちは、検証器修正後は確認されていない。
- 異行動バッチは現カードプールでは少なく、仕様化すべき論点を絞れる。

### 慎重に見る理由

- 平均ターンと15T以上率が増える。
- 甲殻菌糸とエース遂行1で引き分け/長期化が増える。
- 防御 > 攻撃は観測できたが、攻撃 > 回復は現カードプールだけでは観測が薄い。
- 状態付与、強化、必殺技、複合行動をどの優先度に置くかは未決。

## ユーザー判断

マス優先 > レアリティ、同AG/同マス/同レアの最大2体バッチは採用する。

ただし、この採用は同AG解決の構造ルールとしての採用である。同AGバッチ内で異なる行動種がぶつかった場合の詳細、つまり防御、攻撃、回復、状態付与、強化、必殺技、複合行動の優先度は別途P0として詰める。

本実装は、各行動種の優先度詳細とセットで行う。

## 採用範囲

マス優先 > レアリティ、同AG/同マス/同レアの最大2体バッチは採用済み。

ただし本実装前に、次のP0判断を切り分ける。

| 優先度 | 判断事項 | 推奨 |
|---|---|---|
| P0 | マス優先 > レアリティを正本仕様にするか | 採用済み。今回の総当たりでは大崩れなし |
| P0 | 同AG/同マス/同レアの最大2体バッチにするか | 採用済み。説明性とミラー公平性が高い |
| P0 | 同AGバッチ内の同カード/同行動をどこまで真の同時処理にするか | 採用必須。守護/祈祷のような複合行動は部品ごとの同時処理が必要 |
| P0 | 防御 > 攻撃 > 回復を採るか | 追加検証待ち。防御 > 攻撃は有効、攻撃 > 回復は専用テストが必要 |
| P0 | HP0表示と勝敗表示のタイミング | 方針採用済み。カード破壊表示は即時、勝敗表示はバッチ末尾 |
| P1 | 長期化対策をどう置くか | 防御量/持続、回復封じ、防御低下、貫通の調整で見る |

## 次の検証

次は、総当たりでは薄かった防御/攻撃/回復の専用シナリオを作る。

特に見るべきもの:

1. 防御が同速攻撃に間に合うことで、致死を防ぐ役割を持てるか。
2. 回復が同速攻撃後に入り、HP0を復帰させないことで、防御との差別化ができるか。
3. 回復役自身がHP0になっても、予約済み回復を遂行した場合に不自然すぎないか。
4. 回復封じ/防御低下/毒/AG低下が、同AGバッチ内で即時適用か次機会適用か。
5. 複合行動は、行動単位で優先度を持たせるか、部品単位で優先度を分けるか。
