# P0判断用 同AGコスト除外後実測 v0

## 目的

ユーザー判断により、同AGタイブレークからコストを外した。変更後に標準総当たりを再実行し、コスト除外が環境を大きく壊していないか、次のP0判断に進めるかを確認する。

資料内の提案は参考情報であり、この文書では現プロトタイプの実測値とユーザー判断を正とする。

## 変更内容

同AGの行動順は以下にした。

1. レアリティが高い順。
2. 同レアリティで、同じカードかつ同じ行動なら同時解決。
3. それ以外は盤面位置順。

コストは同AGタイブレークに使わない。

## 対象

- 標準総当たり対象: 13デッキ
- 組み合わせ: 13 x 13 = 169組
- 各100戦
- 合計16,900戦

現時点では決定論的なため、同一組み合わせの100戦は基本的に同一展開の反復として読む。

- 2フェーズ制を検討する価値は残る。影響範囲は大きいので、シナリオログと比較実装が必要。

## 同AGタイブレーク内訳

旧基準値と同じく、代表169組を各1戦で比較する。

| 解決種別 | コストあり | コスト除外後 | 差分 |
|---|---:|---:|---:|
| レアリティ | 1,181 / 35.3% | 1,051 / 32.6% | -2.7pt |
| コスト | 558 / 16.7% | 0 / 0.0% | -16.7pt |
| 同時解決 | 1,422 / 42.4% | 1,723 / 53.4% | +11.0pt |
| 盤面位置 | 189 / 5.6% | 453 / 14.0% | +8.4pt |
| 合計 | 3,350 | 3,227 | -123 |

読み:

- コストで分岐していた分は、主に同時解決と盤面位置へ流れた。
- 盤面位置の寄与が増えたため、2フェーズ制を入れない場合でも、配置順の意味は以前より強くなる。
- コストは行動順から切り離されたため、今後はコストを純粋な構築/強度調整レバーとして扱いやすい。

## 判断

採用済みとして進めてよいもの:

- コストは同AGタイブレークに使わない。
- α自由指定は維持する。
- デッキ枚数は、実ルールに合わせてコストが許す範囲で任意にする。現UI/生成器はまだ6枚前提なので、別タスクとして移行する。

次に相談するP0:

1. 同AG解決を2フェーズ制へ寄せるか。
2. 回復は致死を後から救えない、をどの処理単位で正本化するか。
3. 任意枚数化に入る前に、最低限どのカード/生成条件を足すか。
