# 用語整理 v0

## 方針

世界観は「異世界生態系SF」とする。ただし、ゲームシステム理解に関わる語は汎用的なゲーム用語を優先する。

世界観語は、カード名、分類、特性、フレーバー、図鑑テキスト、パックテーマで使う。UIの主要操作や数値には、認知負荷の低い語を使う。

## 基本方針

| 項目 | 方針 |
|---|---|
| デッキ | そのまま `デッキ` |
| カード | そのまま `カード`。別称は要検討 |
| コスト | そのまま `コスト` |
| 地形 | そのまま `地形` |
| HP/AT/AG | そのまま `HP/AT/AG` |
| ダメージ/回復/バリア | 汎用ゲーム用語を使う |
| 大将 | `アルファ` / `α` に置き換える |
| 世界観語 | フレーバー、分類、特性、図鑑で使う |

`生態群`、`中核`、`生態圧`、`定着圧` などは世界観には合うが、主要UIでは重い。現時点では採用しない。

## アルファ用語

旧称 `大将` は軍事色が強いため、正式に `アルファ` / `α` へ置き換える。

採用理由:

- 動物の群れにおけるアルファを知っている人には直感的。
- `α` の1文字表示がUI上便利。
- 他ゲームと異なる用語になり、凡庸感を少し減らせる。
- 世界観に合い、単純にかっこいい。

| 表記 | 使いどころ | 備考 |
|---|---|---|
| アルファ | 初回説明、文章、チュートリアル | 役割を説明しやすい |
| α | UIラベル、カード上の短縮表示、コスト表示 | 1文字で表示できる |
| アルファ個体 | 図鑑、フレーバー | 群れの中心個体として説明する時に使う |

例:

| 場所 | 表示例 |
|---|---|
| ボタン | αに指定 |
| カード詳細 | α特性 |
| コスト表示 | コスト 4 / α 6 |
| 短縮ラベル | α6 |
| 勝利条件 | 相手αを撃破 |
| 図鑑テキスト | 群れでは大型個体がアルファとして行動する |

初回チュートリアルでは「αはデッキの中心個体。相手のαを倒すと勝利」と説明する。

## 実装方針

用語はプロトタイプ上でも可能な限り中央管理する。

| 対象 | 方針 |
|---|---|
| UIラベル | `TERMS` から参照する |
| ログ/説明文 | 表示直前に `uiText()` を通す |
| カードデータ文 | 当面は旧語が残っても `uiText()` で吸収する |
| 内部スキーマ名 | 保存形式が固まるまで `generalCost/generalSkill/general` を維持してよい |
| 将来の内部名 | カードデータ移行時に `alphaCost/alphaTrait/isAlpha` へ寄せる |

新しい画面や説明関数を追加する時は、表示文字列を直接 `textContent` や HTML に流し込まず、`TERMS` または `uiText()` を経由する。

## カードの別称

`カード` はUIで残す。世界観上の呼び方は複数候補がある。

| 候補 | 長所 | 懸念 | 使いどころ |
|---|---|---|---|
| 生物 | 世界観に合う | 無機械生命、菌糸、結晶生命を含めると少し狭い | 図鑑、説明文 |
| 種 | 生態系らしい。量産カードに向く | ゲーム用語としてはやや硬い | カード分類、図鑑 |
| 個体 | 盤面上の1体を表しやすい | カードそのものとはズレる | 戦闘ログ、配置済みカード |
| モンスター | 分かりやすく訴求力がある | 既存作品感、ファンタジー感が強い | マーケ表現、カジュアル説明 |
| クリーチャー | TCG文脈で通じる | MTG感が強い。日本語UIでは少し硬い | 設計用語 |

暫定推奨:

```text
UI: カード
図鑑/フレーバー: 種、個体
マーケ文言: 生物、モンスターも検討
```

例:

- カード一覧
- カード詳細
- 図鑑: 観測された種
- 戦闘ログ: 個体が前進

## 盤面用語

| 現仮称 | UI推奨 | 内部名候補 | 備考 |
|---|---|---|---|
| 前列 | 前衛 | `rank = 0` | 敵に最も近い奥行き |
| 中列 | 中衛 | `rank = 1` | 前衛と後衛の間 |
| 後列 | 後衛 | `rank = 2` | 自分側に近い奥行き |
| 上段 | 左列 | `lane = 0` | 自分視点で左 |
| 中段 | 中央列 | `lane = 1` | 自分視点で中央 |
| 下段 | 右列 | `lane = 2` | 自分視点で右 |
| 同段 | 同列 | `sameLane` | 同じ左/中央/右列 |
| 前へ詰める | 前進 | `advanceUnits` | 前方の空きマスへ移動 |
| 大将護衛 | α保護 | `alphaGuarded` | αの前方に味方がいる状態 |

マス番号は正式な設計用語にはしない。敵味方反転、前進、同列判定で誤読しやすいため、内部処理は `rank/lane` を基準にする。

## 命名方針

カード名は、固有の英雄名ではなく、種名、俗称、観測名に寄せる。

| 避けたい方向 | 推奨方向 |
|---|---|
| ゼウス | 雷を帯びた高地性飛行種 |
| アテナ | 反射殻を持つ防衛性群体 |
| 炎の勇者 | 発酵ガスを着火する大型爬虫類 |
| 魔法使い | 発光胞子で神経伝達を乱す菌糸種 |
| 騎士 | 甲殻を盾状に展開する前衛種 |

名前の候補例:

- 珪殻竜
- 霧鰓獣
- 黒潮の群泳体
- 星喰いの幼生
- 結晶背の古角獣
- 雷嚢翼
- 腐白の菌糸母体
- 灰鱗の地潜り

## 避ける用語

世界観の軸を守るため、正式カードでは以下を避ける。

| 避ける語 | 理由 |
|---|---|
| 兵士、将軍、大将 | 軍事/人型ファンタジーに寄る |
| 勇者、騎士、魔法使い | 剣と魔法の職業感が強い |
| 神、女神、英雄の固有名 | 神話カード化へ流れやすい |
| 職業名そのもの | 生態由来の能力設計から外れる |
| 人型キャラ前提の技名 | 生物種の行動として説明しづらい |

ただし、観測者側の俗称として `雷神竜`、`白王種` のような呼び名を使う余地はある。直接 `ゼウス`、`アテナ` のようにしない。
