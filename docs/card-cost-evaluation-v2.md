# 現行カード点数評価 v2

## 前提

この文書は、現行プロトタイプの `SCORING_RULES` と `CARD_SCORE_INDEX` から出した点数スナップショットである。

点数はカードの最終強度を決めるものではない。新カード作成時の初期見積もり、同コスト帯の異常値検知、総当たり結果との乖離確認に使う。

現行の同速処理は、AG同値の場合に「レアリティが高い順、同じカードかつ同じ行動なら同時解決、盤面位置順」で解決する。コストは同速タイブレークに使わないため、コスト調整は行動順を直接変えない。高レアカードは枚数制限がかかる前提なので、同速優先権も高レア採用理由の一部として扱う。

## 代表デッキ点

| デッキ | C | デッキ点 |
|---|---:|---:|
| 疾走捕食 | 30 | 832.7 |
| 甲殻菌糸 | 30 | 662.6 |

甲殻菌糸は点数上かなり低いが、実戦ではタイタンミセリウムを守る構造によって勝てている。これは「同じコスト内で勝ち筋を最大化する」というゲームの核が表れている良い例であり、カード単体コストへシナジー分を課税しない方がよい。

現状は、疾走捕食が腐蝕制圧に強く、甲殻菌糸が疾走捕食と腐蝕制圧に強い。完全な三すくみにはなっていないが、甲殻菌糸と腐蝕制圧は9T決着で、対策や配置調整の余地が残る程度の差と見る。

## 読み取り

高く出ているのは、サーチ、範囲攻撃、AG操作、中後衛アクセス、早い必殺技を持つカードである。これは設計上の警戒対象と一致している。

低く出ているのは、防御、回復、バリア、必殺技短縮など、単体では勝利条件へ直結しにくいカードである。ただし、甲殻菌糸の実戦結果を見る限り、これらはエース遂行や継続ダメージ耐久のエンジンとして組むと点数以上に働く。

次の改善では、個別カード点とは別に [勝ち筋構築セオリー v0](./win-plan-construction-theory-v0.md) と [デッキ検証指標 v0](./deck-validation-metrics-v0.md) を使う。これはコストへ足す点数ではなく、各勝ち筋と構築エンジンの最適候補群が、強すぎない範囲で成立しているかを確認するための監査軸とする。
