# 現行カード点数評価 v1

## 前提

[カードコスト点数モデル 叩き台v1](./card-cost-scoring-draft-v0.md) に基づき、現行プロトタイプの全カードを概算評価する。

マス番号は正式な設計用語にはしない。盤面評価は、前衛/中衛/後衛と左列/中央列/右列、内部処理は `rank/lane` を前提にする。

## 採点式

```text
通常評価点 =
  HP * 0.45
+ AG * 0.35
+ 前衛行動点 * 0.20
+ 中衛行動点 * 0.26
+ 後衛行動点 * 0.32
+ 通常能力点
```

```text
α評価点 =
  通常評価点
+ α特性点
```

ATは主に行動の効果量点で評価する。素体ステータス点には入れず、ATの価値は「どの行動に乗っているか」で見る。

## 妥当性評価

全体として、点数システムは現状の問題をかなり拾えている。

特に、ソード、ローグ、コマンダーが通常コスト4として高く出る点は妥当。これは高AG、AG補助、サーチ攻撃、中後衛アクセスが重なっているためで、過去のテストで速攻/奇襲/先制集中が強かったこととも一致する。

一方で、シールド、プリースト、ブレイカーが低く出る点も大きくは妥当。これらは耐久、回復、決着補助の性格が強いが、現環境では相手αを倒す速度に変換しづらい。特にプリーストは、治癒陣が同列かつ負傷味方限定で、攻撃も伴わないため行動価値が低く出ている。

ビルダーは点数上やや高いが、実戦では地形: 城壁護衛が弱かった。これは点数表が守護+指揮の柔軟性を評価している一方、城壁軸の勝ち筋変換力をまだ十分に評価できていない可能性がある。ビルダー単体を弱体化するより、城壁/耐久側の勝ち筋を先に確認した方がよい。

ロードはαコスト8で妥当。以前の概算では全体開幕AT/AGを過小評価していたが、効果要素ベースでは全体AG操作として重く見られるため、コスト8の説明がつく。

## 調整優先度

優先度高:

- ソード: C4/α6として高すぎる。高AG、HP満タンAG+5、中衛/後衛の奇襲が重なり、速攻と中後衛処理を両立しすぎている。C5化、AG低下、または中衛/後衛の片方から奇襲を外す候補。
- ローグ: C4/α6として高い。奇襲役として強いのはよいが、α特性の開幕斥候AG+6まで持つため、α時は特に危険。C5化、奇襲ダメージ低下、またはα特性弱体化候補。
- コマンダー: C4/α6として高い。指揮が中衛/後衛の両方にあり、AG+8が即時行動順へ反映されるため、点数以上に試合を壊しやすい。AG+6化、対象数制限、またはC5化候補。

優先度中:

- プリースト: やや低い。回復特化を成立させるなら、治癒陣に小装甲、全体ではなく同列2体保証、または小攻撃を追加する候補。
- シールド: やや低い。平地では高HP以外の勝ち筋が薄い。海適性を前提にするなら海上能力を強くし、そうでないなら通常コストを再考。
- ブレイカー: やや低い。後衛待機が重く、低AGのため決着行動まで届きづらい。後衛に自己AT準備、前衛移動補助、または弱い遠隔行動を持たせる候補。

監視:

- キャノンα: α時やや高い。開幕掃射と後衛掃射が重なるため、前衛崩壊が速すぎるなら開幕掃射の威力か発動条件を下げる。
- メイジα: α時やや高い。回復、狙撃、指揮、全体装甲が揃っていて、構築次第で万能化しやすい。
- ビルダー: 点数はやや高いが、城壁軸の実測が弱い。単体弱体化より、耐久勝ち筋側の再検証を優先する。

## 現時点の結論

現行コストで大きく危ないのは、ソード、ローグ、コマンダー。いずれもAG/サーチ/中後衛アクセスのどれか、または複数を持つ。

逆に不足しているのは、プリースト、シールド、ブレイカー。これらは耐久や決着補助の役割はあるが、勝利条件への変換速度が足りない。

この点数表は、速攻/奇襲/先制集中の強さを説明できている。一方で、耐久型の実力評価には「何ターン生存を伸ばしたか」だけでなく「その間に何点分の攻撃機会を作ったか」を追加変数として入れる必要がある。
