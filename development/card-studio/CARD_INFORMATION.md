# カード情報規格（カード設計室）

更新：2026-09-18。カード固有の情報を下記18項目で管理する。設計意図・想定用途・調整履歴は開発用の `notes` / `history` に分ける。

| 必須項目 | 記述・表示 |
|---|---|
| イラスト | カード画像 |
| カード名 | 固有名 |
| コスト | 数字 |
| αコスト | `α3` 等。α指定時の総コスト |
| レアリティ | C / R / SR / UR のアルファベットアイコン |
| 分類 | アイコン。タップで名称・説明 |
| 得意地形 | 該当する全アイコン。タップで得意地形の説明と名称。該当なしは空欄 |
| 特性 | 共通用語＋数値。効果量（`AT×1.0` 等）は別に保持。タップで詳細 |
| αスキル | 固有名、共通の条件・時点、種類アイコン、効果ごとの対象と内容 |
| HP | 数値 |
| AT | 数値 |
| AG | 数値 |
| 必殺技 | 固有名、`5T` 等、種類アイコン、最大3効果 |
| 前衛行動 | 固有名、種類アイコン、最大2効果 |
| 中衛行動 | 同上 |
| 後衛行動 | 同上 |
| 初期配置制限 | デッキ構築時に置けないマス。例：前衛不可 |
| 枚数制限 | デッキ全体で合算する制限カードの区分。例：2枚制限 |

必須は情報欄を持つという意味。特性・スキル・行動の効果なしを認め、表示は「なし」。二つの構築制限も未指定なら「制限なし」。強い性能に対するペナルティ・調整として付ける。

## 初期配置制限

- 味方側3×3の禁止マスを選ぶ。前衛・中衛・後衛の一括切替と、個々のマスの切替を併用できる。
- 禁止マスは **×**。前衛3マスなら短い表示は「前衛不可」、一部なら「左前衛不可」等。
- デッキ構築時の初期配置だけを表す。戦闘中の前詰め・移動を禁止する指定とは別。
- `card.initialPlacementForbidden: number[]`。0〜8の重複なし整数。`[]` は制限なし。
- 格納順は各行で前→中→後、行は左→中央→右。前衛は `[0,3,6]`。味方図は視覚上、後・中・前の順に並ぶ。

## 枚数制限

- `card.deckLimit: number | null`。正の整数は「n枚制限」、`null` は制限なし。
- 同名カード単位の採用上限ではなく、該当する制限カードをデッキ全体で合算する区分。
- 制限なしのカードは、この制限の合算に含めない。デッキ全体の9マス・30コストなどの共通制約は別に適用する。
- 入力UIは制限なし／1〜9枚制限。取り込んだ10以上の値も保持して表示できる。
- **合算する区分の方向は確認待ち**。「2枚制限以上」が「同じか厳しい制限（1＋2）」か「数字が2以上（2＋3等）」かは未確定。現版は区分の入力・保存・表示までであり、この未決部分の判定式を追加しない。

旧データで両項目が欠けている場合は制限なしとして読み、既存の内容は書き換えない。仕様JSONへ出すときは `[]` / `null` を補う。保存・複製・DB書き出し／取り込み・変更履歴に両項目を含める。

## 対象図と効果記述

- **範囲内すべて**：範囲の入力だけで対象指定を完結させる。条件・順位・人数の入力欄は出さない。
- **サーチ**：サーチ範囲＋サーチ条件＋選び方。陣営・自身・生存状態、同値・対象なし時の規則は必要時に開く。
- 絶対位置の図には自身マークを出さない。相対位置だけ **●** を出す。前・中・後衛行動は対応する衛の中央が表示基準。
- 効果範囲は **塗りつぶし**、サーチ範囲は **斜線＋破線**。見出し・凡例も付け、色だけで区別しない。
- 効果ごとの発動タイミングは、どちらの対象指定でも入力できる。共通設定に従う場合は既存の行動枠の設定を使う。
- 対象を最初に固定するか、各回の前に取り直すかは、発動タイミングとは別に設定する。
- 詳細な条件構造、非表示の条件の保持、旧形式の扱いは [効果対象規格](TARGETING.md) を参照。

効果は表示順に記述し、対象・種類・量・期間・固有条件をそれぞれ持つ。即時は期間省略、持続は `2T`、常時は「常時」。自身のATだけ `AT` と略し、それ以外の参照元は明記する。

## 実装範囲

カード設計室の入力・プレビュー・設計データの保存／出力へ反映する。ゲーム本体でのデッキ制約の強制、実カードへの制限付与、対象の実行処理は接続時に別途実装・検証する。
