## 実装した範囲

- A旧表示 / Bビジュアル表示。親画面の再生位置から同じ記録の前後状態を表示する。
- Bは盤面、行動順、現在行動、HP、α保護/露出、状態、装甲、AT/AG変化、必殺ゲージを優先する。
- 行動順は実リプレイの実行順で、同時成立した最大2体は一組として表示する。AGと位置・レアリティは詳細で確認できる。
- 実際の対象を塗り、既存ログの範囲マスを破線で表示する。カード詳細の範囲図は候補範囲を表し、単体選択では「1体」を明記する。
- 観戦の一時停止、前/次、先頭/最後、ターン移動、スクラブ、速度、対象/結果の切替。
- 選択カードの詳細、状態の付与元/失効ターン、効果説明、基準量。期間は失効ターンから計算し、初回付与期間を残期間として誤表示しない。
- 行動バッチ前後のHP/AT/AG/装甲/ゲージ差分、状態付与/更新/解除・失効、α露出、移動。詳細な順序はその行動のログに残す。
- 編成選択、盤面を選んだカード/地形/αの編集、比較版内の編成保存。細かなカード編集・新カード追加はA旧表示の既存エディターを使い、Bへ戻るとカードプールと編成を再読する。
- 編成やカードが変わったら古いリプレイを無効化。観戦中の選択は個体IDで追跡し、移動で別カードへ選択が移らないようにした。
- モバイルはタップで詳細を固定する下部パネル。意味を色だけに依存させず、状態や操作のアイコンに名称を付ける。

## 試遊で見たいこと

1. 同じ場面をA/Bで見て、発動者・実対象・HP変化を探す時間が短くなるか。
2. 同時成立が「片側が先に倒した」ように見えず、両者の成立を理解できるか。
3. 毒、防御低下、装甲、α保護の違いと失効時点を、必要なときに確認できるか。
4. スマホで詳細を開閉しながら盤面へ戻れるか。カード名、状態アイコン、数値の大きさは十分か。
5. アイコンを覚える負担に対して、文章を読む量が減った利点が上回るか。

試遊の時間/誤答数はまだ測っていない。「文字量半減」「認知負荷半減」は達成済みと扱わない。
