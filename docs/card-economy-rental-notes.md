# カード入手経済とレンタル/恒久化設計メモ

## 目的

スカイガレオン系の「編成を考え、試し、環境に合わせて検証する楽しさ」を新作戦略ゲームに取り入れるため、カード入手経済とレンタル/恒久入手の設計方針を後続検討用に整理する。

## 現時点の前提

- 完全ランダムガチャ偏重は、スカガレ型の検証性と相性が悪い。
- 対戦準備の摩擦を下げる思想は、ポケモンチャンピオンズ型の方向性を参考にする。
- カードは広く試せるようにし、恒久入手は少しずつ進む形にする。
- 課金は勝敗そのものではなく、研究速度、複数デッキへのアクセス、所有感を買うものに寄せる。

## 後続検討の論点

- お試しカード、レンタルカード、恒久入手カードの違いと使い分け。
- ゲーム内通貨、生成素材、チケット、シーズン報酬の役割分担。
- 無課金/微課金でも環境デッキ1つへ現実的に到達できる速度。
- 課金者が複数デッキを早く試せるが、勝敗を直接買えない線引き。
- カードプール更新、レギュレーション、ローテーションの扱い。
- 初心者向け配布と、初期体験で試せるカード範囲。

## 次回の入り口

まずは「全カードを常時レンタル可能にするか」「制限付きレンタルにするか」「恒久化の価値をどこに置くか」から検討する。
