# 現行カード点数評価 v3

## 前提

この文書は、自己完結最大値課税を入れた後の `SCORING_RULES` と `CARD_SCORE_INDEX` から出した点数スナップショットである。

v2からの主な変更は以下。

- 範囲ダメージ係数を `0.85 -> 0.95` に上げた。
- 前衛全体攻撃のカード単体評価用期待対象数を `2.2 -> 2.6` 相当に上げた。
- 後衛掃射補正は、評価上も後衛スロットの掃射にだけ乗るようにした。
- `openingBarrage` は固定54点ではなく、カード自身のAT、前衛全体範囲、開戦時タイミング、自己能力 `rearCannon` との重なりを含む動的評価にした。

点数はカードの最終強度を決めるものではない。新カード作成時の初期見積もり、同コスト帯の異常値検知、総当たり結果との乖離確認に使う。

## ボルカノドレイクの読み

v2では、ボルカノドレイクは通常181.3でC5として高い、α215.7でα8として妥当だった。

v3では、通常197.9、α277.0になった。通常もC5として明確に高く、αはα8妥当帯の上限235を大きく超えた。

これは、自動生成候補込み総当たりでボルカノドレイクα入り盤面制圧が非ミラー全勝級になった結果と整合する。問題は盤面制圧テンプレート全体ではなく、ボルカノドレイクの自己完結最大値が現コストに収まっていない点である。

## 次の調整判断

ボルカノドレイクは、まずコスト/レアリティでどこまで吸収できるかを見る。

- 通常C5は低すぎる。通常C6相当以上として扱う。
- α8は低すぎる。α9以上の帯を追加するか、α効果量を下げる必要がある。
- コスト上げだけで非ミラー全勝が残る場合は、`openingBarrage` の威力、条件、または後衛掃射補正との重なりを調整する。

圧倒的に強い/弱い生成候補は残す。勝ち筋間の比較では一時的に異常値枠として分けるが、原因カードを調整してから再評価する。
