# 初期カードプール v0

## 方針

24枚で、過去に挙げた勝ち筋と対策を全部入れようとしない。初期プールでは、まずオーソドックスな3すくみを成立させる。

採用する主軸:

| 軸 | 方向性 | 強い相手 | 苦手な相手 |
|---|---|---|---|
| 疾走捕食 | 高AG、単体突破、中後衛狙い、α露出咎め | 腐蝕制圧 | 甲殻菌糸 |
| 甲殻菌糸 | 装甲、回復、前衛固定、α保護 | 疾走捕食 | 腐蝕制圧 |
| 腐蝕制圧 | 範囲攻撃、後衛圧、回復封じ、装甲対策、AG干渉 | 甲殻菌糸 | 疾走捕食 |

狙い:

- 疾走捕食は、低耐久の支援/制圧カードを発動前に倒す。
- 甲殻菌糸は、疾走捕食の確定数をずらし、前衛を維持する。
- 腐蝕制圧は、回復役や装甲役を範囲/後衛圧/妨害で崩す。

水棲、地形、必殺技短縮、分類統一は今回は横断要素に留める。専用デッキとして成立させるのは次段階でよい。

## この段階で入れないもの

| 後回し | 理由 |
|---|---|
| 蘇生 | 処理順、勝利判定、ログ負荷が高い |
| 配置交換 | 盤面ルールとα露出の調整が重い |
| デコイ生成 | カード枚数、コスト、前詰め処理を増やす |
| 本格毒デッキ | 継続ダメージと回復封じの両方を入れると耐久対策が過剰になりやすい |
| 必殺技短縮エンジン専用デッキ | まず必殺技そのものの圧を見てからでよい |
| 分類統一エンジン専用デッキ | 統一が自動正解にならないよう、初期は匂わせに留める |

## 次に確認すること

1. 3すくみの各デッキが6枚30コスト以内で自然に組めるか。
2. 疾走捕食が腐蝕制圧へ先手を取れるか。
3. 甲殻菌糸が疾走捕食へ耐久で勝てるか。
4. 腐蝕制圧が甲殻菌糸へ膠着せず勝てるか。
5. 水棲大型2枚が、単なる高コスト高性能になっていないか。
6. 必殺技が「膠着打開」になっているか、「発動したら終わり」になっていないか。
