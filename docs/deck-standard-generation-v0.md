# 標準デッキ生成ルール v0

## 目的

バランス調整時に、勝ち筋ごとのサンプルデッキ候補を自動生成できるようにする。

ここでいう標準デッキは、環境の最強デッキではない。各勝ち筋が本来成立する構造を持っているか、対戦後の検証目安に届き得るかを確認するための、比較基準となるサンプルデッキ群である。

## 基本方針

| 方針 | 内容 |
|---|---|
| 勝ち筋ごとに生成する | 一点突破、盤面制圧、エース遂行など、同じ階層の勝ち筋ごとに候補を作る |
| 構築エンジンは指定条件にする | 分類統一、特性統一、地形、必殺技短縮などは勝ち筋ではなく、勝ち筋を成立させる手段として扱う |
| 自分の構築内で条件判定する | 採用カード、行動タグ、対象、配置から計算できる条件を使う |
| 複数候補を残す | 1勝ち筋につき1デッキだけにしない。構築ミスと勝ち筋の弱さを分離する |
| シナジー点は足さない | 噛み合いそのものはコストに課税しない。生成条件と検証指標で見る |
| 実戦結果で補正する | 事前評価で候補を絞り、総当たりシミュレーションで過不足を判断する |

## 判定レイヤー

自動生成で使う条件と、対戦後に見る指標は分ける。

| レイヤー | 使う場所 | 例 |
|---|---|---|
| 生成条件 | 候補デッキを抽出する時 | 同じ対象条件の攻撃が2枚以上、エースへ届くバフ/保護が3件以上 |
| 事前推定 | 候補を並べ替える時 | 配置込みの集中ダメージ、総ダメージ、支援命中数、必殺到達ターン |
| 対戦検証 | 総当たり後に調整判断する時 | 実際の初撃破ターン、エース生存ターン、主軸行動回数、勝率 |

例えばエース遂行の「5T以上生存」は、自動生成条件にはしない。相手が一点突破か盤面制圧かで大きく変わるためである。生成時には「エースにバフ/保護/短縮が届く構造を持つか」を見る。実際に5T以上生存したかは、対戦検証で見る。

## 入力データ

標準デッキ生成に必要な入力は以下。

| 入力 | 内容 |
|---|---|
| カードプール | カードID、コスト、レアリティ、分類、特性、HP/AT/AG、前中後衛行動、必殺技 |
| 行動タグ | 行動IDから展開される、位置、効果種類、対象、威力、状態異常、持続など |
| 勝ち筋テンプレート | 勝ち筋ごとの生成条件、必須出力、推奨補助、危険フラグ |
| 構築エンジン指定 | 分類統一、特性統一、地形、必殺技短縮、α支援などの採用有無 |
| ルール制約 | デッキ枚数、最大コスト、αコスト、レアリティ枚数制限、同名制限 |
| 検証相手 | 同コスト帯の標準デッキ群、苦手想定、得意想定、ミラー |

## 生成手順

1. 勝ち筋テンプレートを選ぶ。
2. 必須の出力方式を満たすカードを主軸候補として抽出する。
3. 指定された構築エンジンに合うカードを補助候補として抽出する。
4. α候補を選ぶ。
5. コスト、レアリティ、枚数制限を満たす組み合わせを列挙する。
6. 各カードの配置を列挙し、前中後衛行動から検索用レコードを展開する。
7. 事前評価で生成条件未満の候補を落とす。
8. 候補同士の重複が強すぎる場合は、多様性を保つために近い候補を間引く。
9. 残った上位候補を総当たりシミュレーションへ送る。
10. 結果から、カード単体、行動要素、対象範囲、持続、必要ターンを調整する。

## 候補を落とす条件

| 条件 | 理由 |
|---|---|
| コスト上限を大きく余らせる | 同条件比較にならない |
| 主軸行動が配置上ほとんど発動しない | 勝ち筋検証ではなく配置ミス検証になる |
| 勝ち筋の生成条件に届かない | その勝ち筋の標準候補として不適切 |
| 決着手段がない | 妨害、耐久、回復だけでは標準デッキにしない |
| 主軸が1枚に偏りすぎる | そのカード個別評価と勝ち筋評価が混ざる |
| 似た候補が多すぎる | 総当たり結果が同じ構築に偏る |

ただし、エース遂行型のように主軸1枚へ寄せること自体が勝ち筋である場合は、主軸依存を落とす条件にはしない。その代わり、主軸撃破時の負け方を危険フラグとして記録する。

## 事前評価

シミュレーション前に、カードと配置から以下を概算する。

| 指標 | 用途 |
|---|---|
| 集中ダメージ/T | 一点突破、α直接突破の生成条件確認 |
| 総ダメージ/T | 盤面制圧、エース遂行の生成条件確認 |
| 有効対象数 | 範囲攻撃が実際に複数体へ届くか確認 |
| 中後衛到達数 | 支援役、低HP後衛、α露出前後への圧を見る |
| 状態異常付与見込み | 毒、回復封じ、防御低下、AG操作の安定性を見る |
| 延命量/T | 装甲、回復、バリアが遂行時間を稼げるか見る |
| 主軸行動見込み | キーカードが何回行動できそうか見る |
| 必殺技到達ターン | 必殺技短縮や膠着打開力を見る |

この事前評価は候補を絞るための足切りであり、最終判断ではない。実際の勝敗、撃破順、α露出、同速処理はシミュレーションで確認する。

## 自動生成用条件一覧

この一覧は、LLMなしに候補抽出するための足切り条件である。数値はv0の仮値であり、シミュレーション結果に応じて調整する。

| 構築セオリー | 自動生成で満たす条件 | 対戦後に見る目安 |
|---|---|---|
| 一点突破 | 同じ `targetKey` へ届く主軸攻撃が2枚以上。配置込みの集中ダメージが100ダメージ/T相当以上 | 初撃破2〜3T、行動減少が発生する |
| 盤面制圧 | 範囲/複数体攻撃が2枚以上。配置込みの総ダメージが150ダメージ/T相当以上、有効対象3体以上 | 支援網や前線がまとめて崩れる |
| α直接突破 | 壁処理パーツとα到達パーツを両方持つ。α露出後の想定集中ダメージが80ダメージ/T相当以上 | α露出後1〜2T以内に撃破できる |
| エース遂行 | エース候補1枚を指定し、エースへ届くバフ/保護/短縮が合計3件以上。エース自身に高出力行動または必殺技がある | エースが5T前後残り、4回以上行動する |
| 継続ダメージ耐久 | 継続ダメージ付与が2枚以上。HP100相当を4T前後で倒せる継続ダメージ量と、耐久補助2件以上を持つ | 自軍初脱落前に相手1体以上を継続ダメージで倒す |
| ロック/妨害制圧 | 妨害行動が2枚以上。妨害中に進める決着手段を1系統以上持つ | 相手主軸の有効行動を30%以上落とす |
| 反撃/受け崩し | 反撃/反射/接触効果を持つ受け役1枚以上と、受け役を維持する補助2件以上を持つ | 受けたダメージの30〜60%相当を勝ち筋へ変換する |

## 勝ち筋別テンプレート

### 一点突破

| 項目 | 条件 |
|---|---|
| 必須出力 | 同じ対象条件へ集中する単体攻撃、サーチ攻撃、同列攻撃 |
| 生成条件 | 同じ対象条件へ届く主軸攻撃2枚以上。配置込みの集中ダメージ100ダメージ/T相当 |
| 主軸枚数 | 2〜4枚 |
| 重要条件 | 対象条件を揃える。低HP優先、中後衛優先、後衛優先、同列などを混ぜすぎない |
| 推奨補助 | AG強化、AG低下、AT強化、必殺技短縮 |
| 危険フラグ | 低HPサーチで相手の行動量を早すぎる段階で奪う |

生成時は、対象条件の一致度を最優先する。例えば低HPサーチ2枚と後衛優先2枚は、どちらも一点突破に見えるが対象が散る可能性があるため、別候補として扱う。

### 盤面制圧

| 項目 | 条件 |
|---|---|
| 必須出力 | 範囲攻撃、列攻撃、複数体攻撃 |
| 生成条件 | 範囲/複数体攻撃2枚以上。配置込みの総ダメージ150ダメージ/T相当以上、有効対象3体以上 |
| 主軸枚数 | 範囲主砲1〜3枚 |
| 重要条件 | 小打点を有効化する防御低下、回復封じ、必殺技を合わせる |
| 推奨補助 | AT強化、防御低下、必殺技短縮、主砲保護 |
| 危険フラグ | 全対面で後衛支援が行動前に崩れる |

生成時は、総ダメージだけでなく有効対象数を見る。前衛3体だけを削る候補と中後衛へ届く候補は、別系統として残す。

### α直接突破

| 項目 | 条件 |
|---|---|
| 必須出力 | α優先攻撃、露出α特攻、前衛突破、貫通、後衛到達 |
| 生成条件 | 壁処理パーツとα到達パーツを両方持つ。露出後の想定集中ダメージ80ダメージ/T相当以上 |
| 主軸枚数 | 2〜3枚 |
| 重要条件 | αを露出させる手段と、露出後に決める手段を両方持つ |
| 推奨補助 | 一点突破、範囲削り、AGテンポ、必殺技短縮 |
| 危険フラグ | 盤面を取らずにαだけを安定して倒しすぎる |

生成時は「壁を壊すカード」と「αを倒すカード」を分けて評価する。α攻撃だけ強くても、露出が遅ければ標準候補にはしない。

### エース遂行

| 項目 | 条件 |
|---|---|
| 必須出力 | 高出力エースの範囲攻撃、サーチ攻撃、必殺技、毒など |
| 生成条件 | エース候補1枚を指定し、エースへ届くバフ/保護/短縮が合計3件以上。エース自身に高出力行動または必殺技がある |
| 主軸枚数 | エース1枚、支援2〜4枚 |
| 重要条件 | エースだけでなく、支援役自身も一定ターン生存する |
| 推奨補助 | 装甲、回復、AG/AT強化、α支援、必殺技短縮 |
| 危険フラグ | エースが落ちない上に対策しても遂行速度が落ちない |

生成時は、エース候補を先に選び、そのエースの弱点を埋める支援カードを後から選ぶ。例えば「デッキ内最高ATを対象にするバフ」「αを対象にする装甲」「同列の前衛を保護する回復」などが、初期配置でエースへ3件以上届く候補を優先する。αエース型はこのテンプレートの一種として扱う。

### 継続ダメージ耐久

| 項目 | 条件 |
|---|---|
| 必須出力 | 毒、燃焼、出血、寄生などの継続ダメージ |
| 生成条件 | 継続ダメージ付与2枚以上。HP100相当を4T前後で倒せる継続ダメージ量と、耐久補助2件以上を持つ |
| 主軸枚数 | 継続ダメージ付与2〜3枚、耐久2〜3枚 |
| 重要条件 | 毒などが効くまで、被ダメージを25ダメージ/T以下に抑える |
| 推奨補助 | 装甲、回復、回復封じ、AG低下、主軸保護 |
| 危険フラグ | 倒せないが倒されもしない膠着になる |

生成時は、毒の総量だけでなく、毒が撃破へ変換されるターンを見る。耐久だけ厚い候補は落とす。

### ロック/妨害制圧

| 項目 | 条件 |
|---|---|
| 必須出力 | AG低下、行動阻害、AT低下、回復封じ、必殺技遅延 |
| 生成条件 | 妨害行動2枚以上。妨害中に進める決着手段を1系統以上持つ |
| 主軸枚数 | 妨害2〜4枚、決着手段1〜3枚 |
| 重要条件 | 妨害中に盤面、α、毒、必殺技のいずれかで勝利条件へ進む |
| 推奨補助 | 先制AG、妨害役保護、範囲妨害、サーチ回避 |
| 危険フラグ | 相手だけ動けず、対策前にゲームが終わる |

生成時は、妨害カードだけの候補を標準デッキにしない。必ず決着手段を持たせる。

### 反撃/受け崩し

| 項目 | 条件 |
|---|---|
| 必須出力 | 反撃、反射、接触毒、被弾時効果 |
| 生成条件 | 反撃/反射/接触効果を持つ受け役1枚以上と、受け役を維持する補助2件以上を持つ |
| 主軸枚数 | 受け役1〜2枚、補助2〜3枚、決着手段1〜2枚 |
| 重要条件 | 相手が無視しにくい配置または効果を持つ |
| 推奨補助 | 装甲、バリア、回復、挑発、前衛維持 |
| 危険フラグ | 攻撃するほど損だが、無視しても勝てない |

生成時は、反撃量だけでなく攻撃誘導を評価する。相手が攻撃しない場合に何も起きない候補は標準候補にしない。

## 構築エンジン指定

標準デッキ生成では、勝ち筋テンプレートに対して構築エンジンを任意で指定できる。

| エンジン | 生成条件 |
|---|---|
| 分類統一 | 指定分類のカードを一定枚数以上入れる。分類参照効果を持つカードを優先する |
| 特性統一 | 指定特性のカードを一定枚数以上入れる。地形や状態異常と接続する場合は別候補にする |
| 地形 | 指定地形で強くなるカード、または地形デメリットを無視できるカードを優先する |
| 必殺技短縮 | 短縮行動と、短縮先として強い必殺技を両方入れる |
| α支援 | α候補を先に固定し、αを守る/強くするカードを優先する |
| AGテンポ | 主軸行動が相手の想定主軸より先に動くよう、AG強化/弱体を入れる |
| 装甲/回復 | 守る対象を明示し、その対象の行動回数が増える候補を優先する |
| 防御低下/回復封じ | 後続火力または毒が通る候補を優先する |
| スケーリング | 3T目に指定勝ち筋の通常最低ラインへ到達し、4〜5T目に1.5倍以上へ伸びる候補を優先する |
| 条件バースト | 状態、バフ、必殺技、AG順などの条件を揃えたターンに、指定勝ち筋の通常最低ラインを1.5倍以上超える候補を優先する |

同じ勝ち筋でも、採用エンジンが異なれば別候補として残す。例えば一点突破は、AGテンポ型、分類統一型、必殺技短縮型で結果が変わるためである。

### スケーリングエンジン

スケーリングは勝ち筋ではなく、火力や耐久が時間経過で伸びる構築エンジンとして扱う。最終的には一点突破、盤面制圧、α直接突破、エース遂行、継続ダメージ耐久などの勝ち筋へ接続する。

| 項目 | 条件 |
|---|---|
| 必須要素 | ターン経過、撃破、被弾、地形、分類/特性参照で伸びる効果 |
| 生成条件 | 3T目に接続先勝ち筋の通常最低ラインへ到達し、4〜5T目に1.5倍以上へ伸びる見込みがある |
| 重要条件 | 伸びる前は通常構築より弱い。伸びる前に崩される余地がある |
| 危険フラグ | 序盤も強く、後半もさらに強い |

「3T目に通常構築と同じ水準」だけでは下位互換になりやすい。そのため、スケーリング候補は遅れて追いつくだけでなく、その後に通常構築を超える上限を持つことを条件にする。

### 条件バーストエンジン

コンボバーストという呼称は、コンボ全般と混ざりやすい。ここでは「条件バースト」と呼び、特定条件を揃えたターンだけ大きなリターンを得る構築エンジンとして扱う。

| 項目 | 条件 |
|---|---|
| 必須要素 | 状態付与、バフ、AG調整、必殺技、対象条件付き火力など |
| 生成条件 | 条件達成ターンに、接続先勝ち筋の通常最低ラインを1.5倍以上超える |
| 重要条件 | 準備、強化、決着の行動順が成立する |
| 危険フラグ | 成立したら対策不能、または不成立なら完全停止 |

例えば「毒状態の相手へのダメージ増加」は、条件バーストエンジンである。毒を付与するカードと、毒参照で高火力を出すカードを組み、最終的には一点突破や盤面制圧へ接続する。

## 候補選抜の点数

自動生成では、カード単体のコスト点とは別に、候補選抜用の一時点を使ってよい。

| 点数 | 意味 | コスト反映 |
|---|---|---|
| 勝ち筋適合点 | テンプレートの生成条件にどれだけ近いか | しない |
| エンジン適合点 | 指定エンジンの条件をどれだけ満たすか | しない |
| 配置適合点 | 主軸行動が望む位置で発動するか | しない |
| 多様性点 | 既存候補と違うカード/エンジンを使っているか | しない |
| 危険点 | 非ゲーム化、対策不能、膠着の兆候 | しない |

これは候補を並べ替えるための点数であり、カードコストやレアリティの根拠にはしない。コストへ反映するのは、後段の検証で効果要素そのものが過小/過大評価されていると判断した場合だけである。

## 総当たり後の判断

| 結果 | 判断 |
|---|---|
| 生成条件を満たし、勝率は極端でない | 標準候補として採用 |
| 生成条件を満たすが勝てない | カード追加、効果量、対象、配置適性を見直す |
| 検証目安を大きく超え、複数対面で圧勝 | 効果要素、対象、AG、必殺必要ターンを見直す |
| 得意対面に勝ち、苦手対面も工夫で動く | 良好 |
| 苦手対面に現実的な対策候補がない | 対策カード追加、対象範囲、貫通、状態耐性を検討 |
| ミラーで引き分ける | 即問題にしない。環境が停滞する場合のみ調整 |

## 実装順

1. カード行動から検索用レコードを展開する。
2. 勝ち筋テンプレートを中央定義化する。
3. 指定勝ち筋に合うカード候補を抽出する。
4. コスト上限内でデッキ候補を列挙する。
5. 事前評価で生成条件未満を落とす。
6. 上位候補を総当たりにかける。
7. 検証結果をレポート化する。
