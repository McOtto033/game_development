# プロトタイプ世界観改装 v0

## 方針

既存のカードID、行動ID、プリセット構造は維持し、表示名とカード設計項目を異世界生態系SFへ寄せる。

理由:

- 既存の戦闘検証、プリセット、カスタムデッキ保存との互換性を保つ。
- 今後の実運用カード設計で使う `classification`、`traits`、`rarity`、`ultimate`、`codexText` を先に通す。
- 行動や数値は一旦流用し、世界観カードでバランス検証できる状態を優先する。

## 必殺技

必殺技は、指定ターン数経過後に通常行動の代わりに発動する。

実装済みの共通型:

| ID | 機能 |
|---|---|
| `alphaClaw` | 露出α優先の単体大ダメージ |
| `rearExecution` | 中後衛の低HP狙い |
| `lineCrush` | 同列の敵を前から複数攻撃 |
| `wideScorch` | 敵全体への範囲ダメージ |
| `frontBulwark` | 味方前衛への強装甲 |
| `teamBarrier` | 味方全体への装甲 |
| `teamHeal` | 味方全体回復 |
| `deepTeamHeal` | 味方全体大回復 |
| `alphaShell` | 味方αへの装甲と回復 |
| `synapticSurge` | 味方全体へのAT/AG強化 |

## 残課題

- 行動名はまだプロトタイプ用の汎用名が多い。カード固有技へ移行する段階で置き換える。
- 内部タグ `heavy`、`ranged`、`scout` などは地形効果や既存処理互換のため残っている。
- 必殺技の威力、必要ターン、発動ログはまだ調整前。
- 必殺技短縮デッキ用の短縮効果は未実装。

初期カードプールの設計案は [初期カードプール v0](initial-card-pool-v0.md) で管理する。
