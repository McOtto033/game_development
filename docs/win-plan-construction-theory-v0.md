# 勝ち筋構築セオリー v0

## 目的

勝ち筋を同じ階層で整理し、各勝ち筋が満たすべき条件、使える出力方式、構築エンジン、検証指標を定義する。

この文書では、勝ち筋を「何をどう崩して勝つか」と定義する。分類統一、特性統一、地形、必殺技短縮、α支援、AGテンポ、スケーリング、条件バーストなどは勝ち筋そのものではなく、勝ち筋を成立させるための構築エンジンとして扱う。

## 階層

| 層 | 意味 | 例 |
|---|---|---|
| 勝ち筋 | 相手の何を崩して勝つか | 一点突破、盤面制圧、α直接突破、エース遂行、毒耐久 |
| 出力方式 | ダメージや妨害をどう出すか | 単体火力、範囲火力、継続ダメージ、必殺技、反撃 |
| 構築エンジン | 勝ち筋を増幅する土台 | 分類統一、特性統一、地形、必殺技短縮、スケーリング、条件バースト |
| 補助/対策 | 遂行を助ける、または相手を止める部品 | 回復、装甲、バリア、回復封じ、貫通、AG低下 |

例えば分類統一デッキは、分類を揃えること自体で勝つわけではない。分類バフで高AGの一点突破を作るのか、範囲火力を伸ばして盤面制圧するのか、耐久を伸ばして毒耐久するのか、いずれかの勝ち筋へ収束する。

## 基本指標

乱数を使わない前提では、「期待値」よりも「遂行速度」と「被遂行速度」と呼ぶ。

```text
遂行速度:
  自分の勝ち筋が、何ターンで相手の盤面/αを崩すか

被遂行速度:
  相手の勝ち筋が、何ターンでこちらの盤面/αを崩すか
```

| 指標 | 意味 | 注意 |
|---|---|---|
| 総ダメージ | 複数対象に与えたダメージ合計 | 範囲攻撃、αエース、必殺技の圧を見る |
| 集中ダメージ | 特定対象1体へ入るダメージ | 一点突破、サーチ、α直接突破を見る |
| 有効ダメージ | 撃破、α露出、行動回数減少につながったダメージ | 過剰打点や散った範囲打点と分ける |
| 行動減少 | 撃破で相手の以後の行動を何回減らしたか | 一点突破の本質的な報酬 |
| 延命量 | 回復量 + 実軽減量 | 耐久が勝ち筋に変換されているかを見る |
| 状態累積 | 毒、回復封じ、防御低下などの累積効果 | 即時ダメージより時間割引して扱う |

この文書のターン数、生存ターン、初撃破ターンは、対戦後に見る検証目安である。自動生成では相手依存の値を使わず、採用カード、行動タグ、対象、配置から計算できる条件を [標準デッキ生成ルール v0](./deck-standard-generation-v0.md) で定義する。

## 勝ち筋一覧

| 勝ち筋 | 何を崩すか | 典型出力 | 主なエンジン | 実装状況 |
|---|---|---|---|---|
| 一点突破 | 特定の敵1体 | サーチ、同列集中、低HP狙い | AGテンポ、捕食、AT支援 | 実装中 |
| 盤面制圧 | 複数体/前線/支援網 | 範囲攻撃、防御低下、全体必殺 | 範囲強化、必殺短縮、竜/大型 | 実装中 |
| α直接突破 | α本体 | α優先、貫通、露出α特攻 | α露出補助、サーチ、必殺短縮 | 一部実装 |
| エース遂行 | 高出力カードの行動回数 | 範囲、サーチ、必殺技、毒 | α支援、装甲/回復、AG支援 | 実装中 |
| 継続ダメージ耐久 | 時間経過で敵を倒す | 毒、燃焼、寄生、出血 | 耐久、回復封じ、菌糸/甲殻 | 毒のみ実装 |
| ロック/妨害制圧 | 相手の行動や回復 | AG低下、行動不能、AT低下、回復封じ | 妨害保護、先制、範囲妨害 | 一部実装 |
| 反撃/受け崩し | 相手の攻撃行動 | 反撃、反射、接触毒、被弾時効果 | 防御、挑発、前衛固定 | 一部実装 |
| リソース枯渇 | 相手の手段を尽きさせる | 山札/手札/召喚/弾数切れ | 長期戦、妨害、耐久 | 現ルール外 |

## 一点突破

### 定義

特定対象を早期に倒し、相手の行動回数を減らして勝つ。総ダメージではなく、撃破と行動減少への変換が重要。

### 構築条件

| 条件 | 目安 |
|---|---:|
| 主要対象への集中ダメージ | 100ダメージ/T |
| 初撃破ターン | 2〜3T目 |
| 主軸攻撃枚数 | 2〜4枚 |
| 対象一致 | 低HP優先、中後衛優先、後衛優先、同列などを揃える |

### 使えるエンジン

| エンジン | 使い方 |
|---|---|
| AGテンポ | 相手の支援/妨害より先に落とす |
| 捕食/低HP参照 | 削った対象へ火力を集中する |
| 地形/高地 | 後衛攻撃や先制火力を伸ばす |
| 分類/特性統一 | 高AG/サーチ火力を横断強化する |
| 必殺技短縮 | 早期の単体大技で撃破ラインを越える |

### 評価指標

| 指標 | 見ること |
|---|---|
| 集中ダメージ/T | 狙った対象に実際に何点入ったか |
| 初撃破ターン | 行動減少がいつ発生したか |
| 行動減少 | 撃破で相手の以後の行動を何回消したか |
| 過剰打点 | 撃破後に無駄になった火力が多すぎないか |

## 盤面制圧

### 定義

複数体を同時に削り、前線、支援網、回復/装甲の受け先をまとめて崩す。単体撃破は遅くても、盤面全体のHPを危険域へ落とすことで勝つ。

### 構築条件

| 条件 | 目安 |
|---|---:|
| 総ダメージ | 150〜200ダメージ/T |
| 有効対象数 | 3体以上 |
| 状態補助 | 防御低下/回復封じなど2〜4回/試合 |
| 主砲生存 | 4T以上 |

### 使えるエンジン

| エンジン | 使い方 |
|---|---|
| 範囲強化 | 範囲火力の総量を上げる |
| 防御低下 | 範囲の小打点を有効打点へ変える |
| 必殺技短縮 | 全体/列大技を早める |
| 竜/大型統一 | 高コスト範囲主砲を支援する |
| 地形 | 後衛主砲や特定地形火力を伸ばす |

### 評価指標

| 指標 | 見ること |
|---|---|
| 総ダメージ/T | 範囲攻撃の圧が足りているか |
| 有効ダメージ/T | 回復や装甲を越えて盤面崩壊へ進んだか |
| 防御低下後ダメージ | 状態異常が後続火力へ変換されたか |
| 支援役撃破数 | 後衛/中衛がまとめて崩れているか |

## α直接突破

### 定義

α露出後、または保護越しにα本体へ到達して勝つ。盤面を完全に取らなくても、勝利条件へ直接進む。

### 構築条件

| 条件 | 目安 |
|---|---:|
| αへの集中ダメージ | 80〜120ダメージ/T |
| α露出後撃破 | 1〜2T以内 |
| α到達手段 | α優先、貫通、後衛/中衛到達、露出α特攻 |
| 露出補助 | 前衛突破、範囲削り、低HPサーチ |

### 使えるエンジン

| エンジン | 使い方 |
|---|---|
| 一点突破 | α前の壁を早く落とす |
| 盤面制圧 | 前衛をまとめて削ってαを露出させる |
| 必殺技短縮 | α到達大技を早く通す |
| AGテンポ | α露出直後に先に殴る |
| バリア/装甲貫通 | 保護されたαへの回答にする |

### 評価指標

| 指標 | 見ること |
|---|---|
| α露出ターン | 勝利条件へ届いたタイミング |
| α撃破ターン | 露出後に決め切れているか |
| αダメージ/T | 盤面外への直接遂行速度 |
| 壁処理効率 | α前の守りをどれだけ早く剥がしたか |

## エース遂行

### 定義

高出力カードを守り、複数回行動させて勝つ。エースはαでも通常カードでもよい。αエース型はこの下位類型である。

### 構築条件

| 条件 | 目安 |
|---|---:|
| エース総ダメージ | 200ダメージ/T |
| エース生存ターン | 5T以上 |
| エース行動回数 | 4回以上 |
| 支援継続 | 主な支援役が3〜4T以上残る |

### 使えるエンジン

| エンジン | 使い方 |
|---|---|
| α支援 | αのHP補正、α特性、α保護を使う |
| 装甲/回復 | エースの行動回数を増やす |
| AG/AT支援 | エースの総出力を上げる |
| 必殺技短縮 | エースの大技到達を早める |
| 支援保護 | エースではなく支援役を守って出力を維持する |

### 評価指標

| 指標 | 見ること |
|---|---|
| エース総ダメージ/T | エースが盤面全体へ出した圧 |
| エース有効ダメージ/T | 撃破、α露出、行動減少につながった量 |
| エース生存ターン | 保護が機能しているか |
| エース行動/必殺回数 | 支援が火力へ変換されたか |
| 支援役生存ターン | 支援が途中で切れていないか |

## 継続ダメージ耐久

### 定義

毒、燃焼、出血、寄生などで相手を時間経過で倒す。遂行が遅い代わりに、装甲や瞬間回復の影響を受けにくい設計にしやすい。

### 構築条件

| 条件 | 目安 |
|---|---:|
| 継続ダメージによる初撃破 | 自軍初脱落前 |
| 標準出力 | 1体あたり50ダメージ/T相当 |
| 被ダメージ抑制後 | 25ダメージ/T以下 |
| 耐える必要ターン | 3〜4T |

### 使えるエンジン

| エンジン | 使い方 |
|---|---|
| 毒性/菌糸/寄生 | 継続ダメージの付与回数を増やす |
| 甲殻/回復 | 継続ダメージが効くまで耐える |
| 回復封じ | 相手の回復で毒を相殺されないようにする |
| AG低下 | 相手の遂行速度を落とす |
| 範囲毒 | 複数体へ時間差の圧をかける |

### 評価指標

| 指標 | 見ること |
|---|---|
| 状態付与回数 | 毒などが安定して入っているか |
| 累積ダメージ | 実際に何点削ったか |
| 継続ダメージ初撃破ターン | 勝ち筋として間に合っているか |
| 自軍初脱落ターン | 耐久が間に合っているか |
| 延命量/T | 遅さを補えているか |

## ロック/妨害制圧

### 定義

相手の行動順、火力、回復、必殺技、対象選択を抑え、相手の遂行速度を落として勝つ。ダメージは少なくても、相手が勝ち筋を通せない状態を作る。

### 構築条件

| 条件 | 目安 |
|---|---:|
| 妨害継続 | 主要ターンの2〜4Tを妨害 |
| 相手主軸行動減少 | 30%以上 |
| 自軍決着手段 | 妨害中にα/盤面/毒のいずれかで進む |
| 妨害役生存 | 3T以上 |

### 使えるエンジン

| エンジン | 使い方 |
|---|---|
| AG低下/AG強化 | 行動順を固定する |
| 回復封じ | 回復型の遂行を止める |
| AT低下/防御上昇 | 火力型の遂行を遅らせる |
| サーチ回避/擬態 | 妨害役を守る |
| 必殺技遅延 | 大技デッキの決着を遅らせる |

### 評価指標

| 指標 | 見ること |
|---|---|
| 相手主軸行動回数 | 妨害でどれだけ減ったか |
| 回復封じ量 | 回復型への回答になったか |
| AG順変更回数 | 行動順に実効変化があったか |
| 妨害中の自軍進行 | ロックだけで終わらず勝利条件へ進んだか |

## 反撃/受け崩し

### 定義

相手の攻撃行動を利用し、反撃、反射、接触毒、被弾時効果で相手を削る。相手が攻撃するほど損をする状態を作る。

### 構築条件

| 条件 | 目安 |
|---|---:|
| 反撃/反射効率 | 受けたダメージの30〜60%相当を返す |
| 前衛維持 | 3〜5T |
| 攻撃誘導 | 相手が無視しにくい配置/効果 |
| 決着補助 | 反撃だけで足りない分を毒/範囲/αで回収 |

### 使えるエンジン

| エンジン | 使い方 |
|---|---|
| 装甲/バリア | 受けながら場に残る |
| 挑発/対象誘導 | 攻撃を反撃役へ向ける |
| 接触毒 | 攻撃してきた相手へ継続ダメージ |
| 回復 | 反撃役を長く維持する |
| 甲殻/巨大 | 高HPで前衛固定する |

### 評価指標

| 指標 | 見ること |
|---|---|
| 反撃/反射ダメージ | 受けが勝ち筋へ変換されたか |
| 前衛維持ターン | 相手の攻撃を受け続けられたか |
| 相手攻撃抑制 | 相手が攻撃しづらい状態になったか |
| 無視された時の出力 | 無視された場合にも勝ち筋が残るか |

## 構築エンジン一覧

| エンジン | 役割 | 収束しやすい勝ち筋 |
|---|---|---|
| 分類統一 | 同分類参照バフや制限付き強化を最大化 | 一点突破、盤面制圧、エース遂行 |
| 特性統一 | 飛行/水棲/毒性/甲殻などの横断効果を最大化 | 毒耐久、地形型、盤面制圧、ロック |
| 地形 | マス補正でステータス/行動を底上げ | ほぼ全勝ち筋 |
| 必殺技短縮 | 大技の到達ターンを早める | α直接突破、盤面制圧、エース遂行 |
| α支援 | αの耐久/火力/行動回数を伸ばす | エース遂行、α直接突破 |
| AGテンポ | 先手、同速、行動順を操作する | 一点突破、ロック、条件バースト |
| 装甲/回復 | 主軸の生存ターンを伸ばす | エース遂行、毒耐久、反撃 |
| 防御低下/回復封じ | 相手の耐久変換を止める | 盤面制圧、一点突破、ロック |
| スケーリング | ターン経過、撃破、被弾、地形などで後半出力を伸ばす | 一点突破、盤面制圧、エース遂行、毒耐久 |
| 条件バースト | 状態、バフ、AG順、必殺技などを揃えたターンに大きく跳ねる | 一点突破、盤面制圧、α直接突破 |

### スケーリングエンジン

スケーリングは、後半に強くなるためのエンジンであり、勝ち筋そのものではない。最終的には一点突破、盤面制圧、α直接突破、エース遂行、継続ダメージ耐久などへ接続する。

自動生成では、3T目に接続先勝ち筋の通常最低ラインへ到達し、4〜5T目に1.5倍以上へ伸びる見込みを条件にする。通常構築へ遅れて追いつくだけでは下位互換になりやすいため、遅さのリスクに見合う上限が必要である。

### 条件バーストエンジン

条件バーストは、特定条件を満たしたターンだけ通常より高い火力や妨害を出すエンジンである。コンボ全般と混ざるため、勝ち筋名としての「コンボバースト」は使わない。

例えば、毒を付与するカードと、毒状態の相手へ高火力を出すカードを組む場合、条件バーストエンジンで一点突破または盤面制圧を狙う構築になる。自動生成では、条件達成ターンに接続先勝ち筋の通常最低ラインを1.5倍以上超えることを条件にする。

## ベンチマーク作成ルール

自動生成の詳細は [標準デッキ生成ルール v0](./deck-standard-generation-v0.md) を基準にする。

| ルール | 内容 |
|---|---|
| 1勝ち筋につき複数候補 | 1デッキだけだと構築ミスと勝ち筋の弱さを分離できない |
| 最適に近い構築で検証 | 意図的に弱い配置や妥協構築は基準にしない |
| 同コストで比較 | 30コストなど同条件で勝ち筋の強さを見る |
| 主軸カードを明示 | `keyCards` として行動回数、必殺回数、生存ターンを取る |
| 使用エンジンを明示 | 勝ち筋とエンジンを混同しない |
| 対照実験を残す | 1枚差し替え、主軸差し替え、支援枚数変更で寄与を測る |
| ミラーは即調整しない | ミラー引き分けは自然に起こり得る。環境がそのミラー一色になる場合のみ問題視する |

## 調整判断

調整が必要なのは、勝ち筋が強いだけの場合ではない。カード入れ替え程度では現実的な勝ち筋がなく、環境が一方的になる場合に調整候補とする。

| 状態 | 判断 |
|---|---|
| 接戦 | 問題なし。ユーザーの工夫で差が出る領域 |
| やや有利 | 問題なし。メタや構築差で回る範囲 |
| 主要勝ち筋の候補群に大きく勝ち越す | 監視 |
| 対策候補を入れても遂行速度がほぼ落ちない | 調整候補 |
| 特定カードが複数勝ち筋で必須化する | コスト/レアリティ/効果量を見直す |
| 勝ち筋が成立しない | カード追加、効果量強化、対象改善を検討 |

点数制へ反映するのは、実戦結果から「毒」「装甲」「範囲」「サーチ」「AG操作」などの効果要素が一律に過小/過大評価されていると判断できた場合に限る。分類統一や必殺技短縮などのエンジン単位で、噛み合いそのものを点数へ足さない。
