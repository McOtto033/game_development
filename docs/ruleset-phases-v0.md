# 段階解禁の仕様 v0

2026-09-07、M1-02で採用済みD8とAD-G03を実装。現在のゲームはCore固定で、実行中の切替UIは追加していない。

## 段階と実装有無

| ID | 順位 | 現在の扱い |
|---|---:|---|
| core | 0 | 現在使える29カード、地形、行動、特性、生成テンプレートを維持 |
| depth | 1 | 継続回復と新規の状態解除を予約。まだ実装を有効化しない |
| metaChanging | 2 | 行動制御と復活を予約。まだ実装を有効化しない |

`RULESET_PHASES` は段階の正本、`ACTIVE_RULESET_PHASE` は現在の実行段階。`unlockPhase` はその要素が使える最初の段階で、後の段階は前の段階を含む。`implemented` は独立した実装状態で、`true` の要素だけを使用可能と判定する。未知の段階IDやメタデータ欠落は使用可能とみなさない。

既存定義にはCore/実装済みの既定値を補う。未実装の継続回復、麻痺、独立したバリア状態はfalseを維持する。新規の予約効果は `unlockPhase` と `implemented: false` を必ず明示する。段階名を後ろへ進めても未実装効果は利用できない。

`barrier` の効果要素は、既存の装甲系行動の分類としてCoreで維持する。独立した `STATUS_EFFECTS.barrier` が未実装であることとは区別する。分類タグや対策候補のメタデータが、それだけで新しい戦闘効果を生むわけではない。

## 本体の参照経路

| 入口 | 判定 |
|---|---|
| `isRulesetEntryAvailable` | 要素自身の解禁段階と実装有無 |
| `isEffectElementAvailable` | 効果自身に加え、`statusKey` を持つ場合はその状態も確認 |
| `isActionAvailable` | 行動自身、実行関数、対象パターン、全効果要素を確認 |
| `isCardAvailable` | カード自身、分類、全特性とその効果、得意地形、3衛の行動、必殺技を確認 |
| `rulesetCatalog(phase)` | 指定段階で利用可能なカード/状態/効果/特性/地形/テンプレートのID一覧 |
| `buildCardActionSearchIndex(cards, phase)` | 使用不能な参照を持つカード全体を検索・生成用レコードから除外 |
| `generateStandardDeckCandidates` | 現段階で使用可能な生成テンプレートを選ぶ |
| `createUnits` | 未解禁カードや実際に配置する未解禁地形をエラーとして拒否 |
| `grantStatusEffect` | 現段階で使用不能な状態は付与しない |

`ACTION_METADATA` にも行動自身の段階/実装有無を記録する。ただし、参照先まで含めた最終的な可否は上記の判定関数を使う。

カード情報を変更した後は既存の `refreshDerivedCardData()` で検索/採点/生成を更新する。カード自身がCoreでも、必要な行動がDepthならCoreの生成候補には使わない。必要な効果が未実装ならどの段階でも使わない。

## 保存と初期運用

カードの保存用正規化は `unlockPhase` と `implemented` を保持する。これらの項目がない既存カスタムカードはCore/実装済みとして扱い、既存の編集内容との互換性を維持する。不明な段階を指定した保存値はCoreへ書き換えず、使用不能と判定する。

今回はCore固定で、既存カードの可否に変更はない。将来、実際に未解禁カードを同梱する時は、公開用のカード一覧/編集候補へカタログの絞り込みを適用し、保存デッキの互換性表示とブラウザでの起動を検証する。その公開UIや動的な段階切替は今回の最小導入には含めない。
