# 大将戦コアルール プロトタイプv0

## 目的

軽量Webプロトタイプで検証するための、最小限の大将戦ルールを定義する。現段階では演出やカード収集ではなく、構築と戦闘ログから勝ち筋が読めるかを優先する。

## 勝利条件

- 各デッキは1枚を大将に指定する。
- 相手大将を倒した時点で勝利。
- 大将が倒れるまでターンを継続する。
- HP/位置が変化しない膠着が3ターン続いた場合は、暫定的に引き分け。
- 実装上の安全上限として80ターンに到達した場合も、暫定的に引き分け。

## 試合展開の目標

- 1〜3ターン目に前中衛が崩れ始める。
- 2〜5ターン目に大将が中列/前列へ引きずり出される。
- 5〜7ターン目に大将撃破で決着する展開を標準にする。
- 標準耐久は、普通の1枚対象攻撃2回と範囲攻撃1回でおおむね倒れる程度を基準にする。
- 現プロトタイプでは、標準HP110〜115、標準AT35〜38前後を初期調整値とする。

## 対戦判定

- 対戦は100戦を1セットとして集計する。
- 100戦内で勝利数が多い側を、その組み合わせの勝者とする。
- 勝利数が同じ場合は引き分け。
- 選択中の組み合わせは、100戦のうち代表1戦をリプレイ確認できる。
- 全プリセット総当たりでは、各プリセット初期地形を使って100戦ずつ集計する。
- バランス調整中は、全プリセットの初期地形を平地に統一する。

## 盤面

- 各プレイヤーは3x3の盤面を持つ。
- 列は前列、中列、後列。
- 中列へ配置するには、同じ段の前列にカードが必要。
- 後列へ配置するには、同じ段の中列にカードが必要。
- 初期配置でも同じ制約を適用し、段の途中に空白を挟んだ配置は不可。
- 通常攻撃は前中衛を崩す方向に寄せる。
- ターン終了時、同じ段で前方に空きがあるカードは前へ詰める。
- これにより、護衛が崩れるほど大将が前線へ出る。

## カード

- 各カードはHP、AT、AG、兵コスト、大将コストを持つ。
- 各カードは前列行動、中列行動、後列行動を持つ。
- 能力は基本1つ、最大2つまでを想定する。
- 大将指定時のみ大将スキルが発動する。
- 追加カードとして、範囲回復のプリースト、大将支援のパラディン、全体大将バフのロードを採用する。

## デッキ/コスト

- デッキ上限は30コストを標準にする。
- 1デッキの標準枚数は6枚。
- 標準構成は4コスト3枚、5コスト3枚を目安にする。
- 大将に指定したカードは、兵コストからおおむね+2コスト上がる。
- 現プリセットは全て6枚、初期地形込みで29〜30/30コストに収める。
- 29コストのデッキは、低コスト地形を1マス入れる余地として扱う。

## モデルデッキ配置

- 王道護衛: 上段はランス+コマンダーの攻撃補助、中央はシールド+ガード大将の護衛レーン、下段はビルダー+ヒーラーの修復レーン。
- 後列奇襲: 上段はソード+ビルダー+ローグ大将、中央はランス+ブレイカー+アーチャーで、前衛を足場に中後列攻撃を通す。
- 海陣防衛: 上段はビルダー+キャノンの砲台レーン、中央はガード+シールド大将+コマンダーの司令塔レーン、下段にヒーラーを置く。
- 前線突破: 上段はソード+ローグの速度レーン、中央はブレイカー+ランス大将+キャノンの突破レーン、下段にヒーラーを置く。

## 地形最適化デッキ

- 地形: 城壁護衛: 城壁上のビルダーを軸に、守護と回復で前線を固定する。
- 地形: 森奇襲: 森のAG補正でローグ大将をさらに速くし、後列へ圧をかける。
- 地形: 海陣: 海上のシールド大将を強化し、海/城壁対象の大将スキルを見せる。
- 地形: 高地砲撃: 高地キャノンの後列掃射で、前列崩しを早める。
- 地形最適化デッキは手動対戦用とし、平地モデルの総当たり集計からは外す。

## 教材デッキ

- 教材: 鼓舞掃射: ATアップを先に入れて、掃射で前列全体を削る。
- 教材: 先制集中: AGアップで行動順を作り、同じレーンへ攻撃を集中する。
- 教材: 装甲護衛: 装甲付与で当該ターンの被ダメージを抑え、前線を長く維持する。
- 教材: 回復粘り: 一撃で落ちない耐久を作り、単体回復と治癒陣で確定数をずらす。
- 教材: 大将スキル軸: ステータス控えめのロード大将を守り、開戦全体バフで初動を作る。
- 教材: エース大将: 高ステータス大将にAT/AG/装甲/回復支援を集めて突破する。
- 教材デッキは手動対戦とリプレイ確認用とし、モデルデッキの総当たり集計からは外す。

## 行動テンプレ

- 斬撃: 最前の敵1体にAT分ダメージ。
- 貫通: 同段の前から2体に小ダメージ。
- 掃射: 敵前列全体に小ダメージ。
- 守護: 自分と前の味方に装甲を付与。
- 鼓舞: 味方前列のATを2ターン上げる。
- 祈祷: 最も傷ついた味方を回復。
- 治癒陣: 同段の傷ついた味方全体を小回復。
- 献身: 味方大将に装甲と小回復を付与。
- 狙撃: 後列を狙う。守られた大将には軽減。
- 奇襲: 中後列の低HPを狙う。
- 指揮: 同段の味方のAG/ATを1ターン上げる。当該ターン内の未行動カードの行動順に反映される。
- 破陣: 露出した大将を優先して大ダメージ。

## 防御/回復

- 現プロトタイプの装甲は、固定値ぶん被ダメージを減らす防御バフとする。
- 標準の守護は、装甲+18/1T。
- 標準攻撃35〜38に対して、約0.5倍ぶんをカットする想定。
- 装甲は被弾しても消費されず、効果ターンが切れると消える。
- 1T装甲は付与されたターン内のみ有効。開幕付与は1ターン目のみ有効。
- ヒーラーの祈祷は、単体回復 max(7, floor(AT×0.75)) に加えて、対象に装甲+6/1Tを付与する。
- プリーストの治癒陣は、同段の傷ついた味方全体を max(6, floor(AT×0.55))+2 回復する。
- パラディンの献身は、味方大将に装甲+26/1Tと max(5, floor(AT×0.35)) 回復を付与する。
- 将来拡張として、1回だけダメージを無効化する障壁、一定量まで肩代わりして消える障壁、割合軽減の結界を検討する。

## 地形

- 構築時にマスへ地形を設定できる。
- 地形にもコストがある。
- カードコストと地形コストの合計をデッキ上限内に収める。
- 地形効果はカードテキストを増やさず、構築の読み合いを増やす役割を持つ。

## 現プロトタイプの制限

- デッキは平地モデル、地形最適化、教材、登録デッキから選ぶ。現プリセットは全て6枚。
- 手動編集では、カード配置、大将指定、地形変更を切り替えられる。
- カードリストと盤面を同じ作業面に置き、カードはアルバム形式でHP/AT/AG/コスト/行動を一覧できる。
- カードはカードリストから盤面へドラッグアンドドロップで配置できる。
- 地形も地形パレットから盤面へドラッグアンドドロップで配置できる。
- 大将指定は、大将指定モードで盤面カードをクリックするか、カード詳細の「大将に指定」ボタンで行う。
- 編集中のデッキは100戦対戦でそのまま検証でき、30コスト以内なら登録デッキとしてブラウザに保存できる。
- 地形は操作を「地形変更」に切り替えてマスをクリックすると変更する。
- カード配置では前方にカードがない中列/後列配置を不可とし、デッキ枚数は6枚までに制限する。
- ゲージ、奥義、同名制限、属性/勢力/種族はまだ簡略化している。
- ターン内の行動順は、未行動カードの中から現在AGが最も高いカードを都度選ぶ。これにより、当該ターンのAGアップが未行動カードの順番に反映される。
- リプレイは簡易アニメーションで、行動者、攻撃範囲、対象、ダメージ、回復、強化、前進、戦闘不能を強調表示する。
- 攻撃フレームは、行動者を2秒強調し、0.2秒後から0.8秒間攻撃範囲を表示し、1.1秒後に対象を変色させ、1.2秒後から0.8秒間ダメージ数値を表示する。
- 貫通、掃射など複数対象の同一攻撃は、1つの攻撃フレームで同時にダメージを処理・表示する。
- 回復フレームは、回復対象を緑で強調し、カード上に回復量を表示する。
- 強化フレームは、対象を強調し、カード上にAT+3/2T、AG+8/1T、装甲+18/1Tのような付与量を表示する。
- 鼓舞、指揮、複数対象の大将スキルなど同一強化は、1つの強化フレームで同時に処理・表示する。
- 行動中カードは枠線と発光で強調する。
- AT/AGが基礎値から変化している場合、AT+3/2T、AG-4のような状態チップで表示する。
- 装甲、初回軽減、遠隔軽減、城壁軽減、大将護衛はカード上の状態チップで表示する。
- カード詳細では、各列の行動を対象マス図、「式」、現在ATでの目安値つきで表示する。
- カードをクリックすると、カード上に行動対象を3x3マス図で示す説明ポップを表示する。
- 行動名、地形名、タグなどの用語はカーソルを合わせると説明を表示する。
- 盤面、カードリスト、カード詳細、検証結果、戦闘ログを一画面の作業面にまとめる。
- 現時点では戦闘が決定論的なため、100戦の結果は同じ展開の反復になりやすい。将来、軽い乱数要素を入れた時に勝率検証へそのまま使う。
