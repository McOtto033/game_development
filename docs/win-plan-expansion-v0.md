# 勝ち筋検証用カードプール拡張 v0

## 目的

現カードプール内の個別性能調整に閉じず、勝ち筋間の比較を進めるために、未検証だった「継続ダメージ耐久」と「反撃/受け崩し」を標準生成・総当たりで検証可能にした。

ロック/妨害は、相手のプランを崩す補助寄りの性質が強く、主勝ち筋化すると調整がシビアになる。そのため標準生成では足切りを厳しくし、現時点では生成候補なしに戻した。

## 実装内容

- 状態効果を追加: 接触毒、反射殻。
- 行動を追加: 毒針、毒雲、棘構え、鏡殻。
- カードを追加: ヴェノムモス、パラサイトモールド、ソーンアネモネ、ミラータートル。
- 反撃/接触毒/反射を点数評価に追加し、カード単体で成立する最大値へ課税した。
- 継続ダメージ耐久の生成では、毒カードだけでなく耐久支援をコアに含めるようにした。
- 耐久系テンプレートの前衛アンカー選択は、攻撃出力ではなく耐久指標を優先するようにした。
- 総当たりサマリーは、自軍/敵軍の向き差を避けるため、総合トップ/最下位を向き補正後の勝率で表示するようにした。

## 生成結果

標準生成は9デッキ。新規に成立した勝ち筋は以下。

- 生成: 継続ダメージ耐久1: コスト30、毒3枚、継続126、耐久3件。αはオブシディアンタートル。
- 生成: 反撃/受け崩し1: コスト29、受け2枚、返し39.4、維持3件、決着2系統。αはオブシディアンタートル。
- ロック/妨害制圧: 足切り条件未達。主勝ち筋ではなく補助パッケージ扱いを維持。

## 読み取り

- 継続ダメージ耐久と反撃/受け崩しは、少なくとも自動生成・総当たりで検証できる状態になった。
- 反撃/受け崩しは全体55%で、腐蝕制圧や盤面制圧1に強く、甲殻菌糸・高速/α直接系に弱い。主勝ち筋より補助寄りの性質が出ている。
- 継続ダメージ耐久は全体27%で弱い。毒量だけでなく、序盤を耐える手段や毒が効くまでの保護設計が不足している。
- 甲殻菌糸95%、α直接突破1 91%が次の異常値候補。勝ち筋比較の前に、甲殻菌糸の耐久/毒エンジンとα直接突破1の速度が標準から外れていないかを分析する必要がある。
