# 非ゲーム化の観測指標 v1

2026-09-07、M1-03 / AD-G04。定義版 `non-game-v1`、JSON形式版 `standard-battles-v1`。

## 再現方法

```powershell
node scripts/report-standard-battles.js
node scripts/report-standard-battles.js --output .autodev/standard-battles-next.json
```

引数なしでは標準出力へJSON、`--output`では指定ファイルへ保存する。既存ファイルは上書きせずエラーにするため、再保存には別名を指定する。Node.js 22以上、追加パッケージ/ネットワーク不要。

今回の機械可読成果物は `.autodev/standard-battles-m1.json`。本体/HTML/起動用DOMダブル/レポート生成器のSHA-256、実際のデッキ定義、全対戦の本体メトリクスを含む。GitのHEADだけでは未コミット本体を識別できないため、ソースハッシュを比較に使う。`.autodev/` はローカル保存でGit管理外。要点は本書へ記録する。

## 測定対象

- `roundRobinPresets()` の標準13デッキ (モデル3、生成10) を、各デッキの地形で両向き・ミラー込み169組、各1戦。本体 `simulateBattle` をそのまま実行する。
- 決定論的な固定編成の測定であり、169個の独立した確率試行ではない。同じ対戦を100回反復しても標本数を増やした扱いにしない。
- `summary` は169組、`nonMirrorSummary` はミラー13組を除く156組。ミラーを混ぜて全体傾向を隠さないよう併記する。
- 新規DOMダブル内の空のlocalStorageで起動する。ブラウザに保存したカード編集やカスタムデッキは対象外。本体の現行データを測定する。
- UIは変更しない。DOMダブルは実ブラウザの表示/保存/リプレイ時間進行を保証しない。

## 定義と分母

| JSON項目 | 定義 |
|---|---|
| `terminalTurns` | 引き分けを含む終了ターンの件数/総和/平均/分布 |
| `settlementTurns` | 勝者が確定した対戦だけの決着ターン。引き分けを除外 |
| `drawTurns` | 引き分けだけの終了ターン。相互撃破、膠着、上限到達の理由はこの指標では分離しない |
| `earlySettlement.byT1/byT2` | T1以内/T2以内に勝者が確定した件数。T2はT1を含む累積。`allBattles` は全対戦、`decisiveBattles` は勝敗確定戦を分母とする |
| `loserActions` | 敗者側全ユニットの通常行動+必殺技の合計を、敗者1陣営1件で集計。引き分けには敗者がないので除外し、`excludedDraws` に件数を示す |
| `firstActionDeaths.allUnits` | 初回KO時に通常行動+必殺技が0回のユニット数 / 全対戦の初期配置ユニット延べ数。勝者・引き分け・生存者をすべて分母に含む |
| `firstActionDeaths.losingUnits` | 同じ死亡条件を敗者側だけで集計。分母は敗者側初期配置ユニット延べ数。引き分け除外数も併記 |
| `effectiveSettlement` / `completeLock` | 未評価。`status: not_evaluated`, `rate: null`。実質決着を実決着で代用せず、未公開の行動制御を理由にロック率0%としない |

率は `numerator` / `denominator` と0〜1の `rate` を持つ。分母0の率と空集合の平均は `null`。デッキごとの率を単純平均せず、該当する延べ件数で計算する。

ターンは本体の戻り値を使う。開戦効果でKOがT0に記録されても、勝敗判定がT1なら実決着はT1。同じターンに行動したかだけで前後関係を推測しない。

「行動」は本体が実行を確定した通常行動と必殺技。待機・対象不在も1行動。α特性、特性の誘発効果、反射、毒の継続ダメージなどは追加の行動に数えない。行動回数は有効打や対策成功回数ではない。

本体のユニット指標に `actionsBeforeFirstKo` を追加。生存中は `null`、初回の `recordKoMetric` で通常行動+必殺技の累計を固定する。再度のKO記録で上書きしない。D4同AGバッチでは両者の保証された行動を効果処理前に数えるため、バッチ途中のHP0を「一度も動けず死亡」と誤認しない。戦闘終了時に未行動でも生存していれば死亡の分子には入れない。

## 今回の実測

| 指標 | ミラー込み169組 | 非ミラー156組 |
|---|---:|---:|
| player勝ち / enemy勝ち / 引き分け | 76 / 76 / 17 | 76 / 76 / 4 |
| 平均終了ターン (引き分け込み) | 8.740 | 7.397 |
| 平均決着ターン (勝敗確定152戦) | 5.487 | 5.487 |
| T1以内実決着 / 全対戦 | 2/169 = 1.18% | 2/156 = 1.28% |
| T2以内実決着 / 全対戦 | 22/169 = 13.02% | 22/156 = 14.10% |
| T2以内実決着 / 勝敗確定戦 | 22/152 = 14.47% | 22/152 = 14.47% |
| 敗者行動平均 | 3018/152 = 19.855 | 同左 |
| 初回行動前死亡 / 全配置ユニット | 12/1846 = 0.65% | 12/1704 = 0.70% |
| 初回行動前死亡 / 敗者配置ユニット | 12/822 = 1.46% | 同左 |

勝敗確定戦の決着ターン分布 (ターン: 件数):

```text
1:2, 2:20, 3:34, 4:20, 5:26, 6:16, 7:8,
9:4, 10:8, 11:4, 14:2, 15:2, 18:4, 19:2
```

引き分け終了ターン分布:

```text
2:1, 4:2, 6:2, 7:1, 8:1, 9:1, 10:1, 27:1, 80:7
```

非ミラーの引き分け4戦はすべて80T。平均終了ターン8.740だけを見ると、勝敗確定戦の5.487Tと長期引き分けが混ざる。今回の数値だけで「非ゲーム化なし」や「面白さ合格」と判断しない。敗者の行動には待機や空振りも含まれ、全体平均は特定対面の偏りを隠す。M1-04では対象4候補を両向き・対面別に分析し、有効な行動へ変換できているかを見る。今回、カード数値の調整はしない。

初回KO時点ではなく戦闘終了時の行動数だけで推定する案も可能だが、KO後の保証行動や将来の復活で意味が変わるため採用しない。復活・追加行動・行動取消・別の決着判定を導入する時はAD-G04と定義版を見直し、旧版と無条件に比較しない。
