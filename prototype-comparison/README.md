# 比較用UI C1

現行 `prototype/` を維持したまま、同じ戦闘処理を使って表示を比較する試作。

- 入口: `index.html`。ビルド・通信不要。
- `baseline/` は2026-09-10の `0b4ff47` のコピー。変更点は保存キー2個と観測ブリッジの読み込みのみ。戦闘仕様・カード数値は変更しない。
- 保存先は `comparison-c1-*`。現行版の保存領域を読み書きしない。
- Aはコピーした旧UI、Bは観戦専用UI。同じ記録位置を共有し、比較版内のカード編集・編成を共用する。
- 最初の有限範囲: 編成選択、配置変更、観戦表示、実記録の行動順、対象強調、状態と差分、停止/前後移動、実ブラウザ確認。
- カードバランス調整・次のマイルストーン開始は含めない。

Pagesへの配置先は `prototype-comparison/`。公開更新は別途pushとデプロイが必要。現行版のURLと内容は維持し、ブラウザの保存先も分離する。PCのローカルHTMLの保存データがスマホへ自動転送されることはない。

観測器は実際の行動バッチ境界で本体を呼び、前後状態と既存イベントを記録する。同AG同位置同レアリティの同時成立を分割しない。行動順は予測ではなく、そのリプレイで実行された順。

状態期間は現在ターンを含む有効期間。毒の残り発動回数とは区別する。数値の内訳は記録されたイベントとHP差分を表示し、存在しない計算根拠を補わない。

完了状況と確認結果は `../docs/ui-comparison-c1.md` を参照。
