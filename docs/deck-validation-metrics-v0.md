# デッキ検証指標 v0

> 2026-09-07 M1-03: 非ゲーム化の測定定義と本体総当たりJSONは [観測指標 v1](non-game-metrics-v1.md) を参照。実決着/実質決着、引き分けを含む終了ターン/勝敗確定戦の決着ターンを分ける。

## 目的

カード単体のコスト採点とは別に、デッキとしての勝ち筋が成立しているか、強すぎないか、対策不能になっていないかを検証する。

この指標はコストへ足す点数ではない。構築で勝ち筋を最大化することがゲームの面白さなので、シナジーそのものには原則として課税しない。

勝ち筋ごとの構築条件は [勝ち筋構築セオリー v0](./win-plan-construction-theory-v0.md) を基準にする。標準デッキ候補の作り方は [標準デッキ生成ルール v0](./deck-standard-generation-v0.md) を基準にする。検証対象は、雑なサンプルではなく、現カードプールで最適に近いと思われる候補デッキ群とする。

## 基本方針

| 項目 | 扱い |
|---|---|
| カード単体点 | コスト設定に使う。カード自身のステータス、行動、対象、状態異常、必殺技、α特性だけを見る |
| デッキ検証指標 | コストには入れない。勝ち筋と構築エンジンの成立度、対策余地、膠着リスクを見る |
| 調整対象 | シナジーそのものではなく、原因となる効果要素、対象、持続、必要ターン、枚数制限を見る |

## なぜシナジー点を足さないか

このゲームは、同じコスト上限の中で「カード単体の強さ」ではなく「勝ち筋の噛み合わせ」を作るゲームである。

例えば甲殻菌糸は、個別カード点では低いが、タイタンミセリウムを守って行動回数を増やすことで実戦上の勝ち筋を作っている。これは本来プレイヤーが発見して快感を得る部分であり、事前にシナジー点としてコストへ課税すると、構築の報酬を削ってしまう。

ただし、シナジーが対策不能な定番解になった場合は調整する。その時も「甲殻菌糸シナジーに+40点」のようにはせず、以下のような単体要素を見直す。

| 問題 | 見直す場所 |
|---|---|
| エースが落ちず、対策が間に合わない | 防御量、防御持続、エースHP、エースAG、後衛到達手段 |
| 守ったエースの火力が高すぎる | 範囲倍率、サーチ対象、必殺技必要ターン、状態異常付与 |
| 回復/防御で膠着する | 回復量、防御持続、毒/防御低下/貫通の回答枚数 |
| 先制で相手の行動量を奪いすぎる | AG操作量、サーチ攻撃点、低HP優先の威力、同速処理 |
| 特定分類/特性統一エンジンが自動正解になる | 強化対象数、強化量、分類対策、地形依存度 |

## 記録する指標

現行プロトタイプでは、`simulateBattle` が1戦ごとの `metrics` を返し、`simulateSeries` が平均値へ集計する。UIでは「検証結果」に主軸行動、延命量、状態付与、α露出、同速処理を表示する。

### 勝敗・速度

| 指標 | 見る理由 |
|---|---|
| 勝率 | 同コスト帯で突出していないか |
| 平均決着ターン | 速すぎる非ゲーム化、遅すぎる膠着を検出する |
| 引き分け率 | ミラーや耐久対面の膠着を検出する |
| α撃破ターン | 勝利条件へ到達する速度を見る |

### 勝ち筋成立度

| 指標 | 見る理由 |
|---|---|
| キーカード生存ターン | エース保護が成立しているか |
| キーカード行動回数 | 守った結果、何回分の攻撃/毒/必殺技に変換されたか |
| 必殺技発動回数 | 必殺短縮エンジンや耐久デッキの決着手段を測る |
| 状態異常付与回数 | 毒、回復封じ、防御低下が勝敗に寄与しているか |
| 防御/回復による延命量 | 耐久行動が単なる遅延か、勝ち筋に変換されているか |

現行で自動取得している内訳:

| 指標 | 内容 |
|---|---|
| 主軸行動回数 | プリセットの `keyCards` に指定したカードの通常行動回数 |
| 主軸必殺回数 | `keyCards` の必殺技発動回数 |
| 主軸生存ターン | `keyCards` の平均最終生存ターン |
| 回復量 | 実際に回復したHP |
| 回復封じ量 | 回復封じ中に無効化された回復試行量 |
| 装甲付与量 | 付与した装甲値の合計。持続込みの装甲ターン値も内部保持する |
| 軽減量 | 装甲、地形、能力などで実際に減った被ダメージ |
| 状態付与 | 毒、回復封じ、防御低下の付与回数 |
| α露出ターン | αが攻撃可能になった最初のターン |
| α撃破ターン | αが倒れたターン |
| 同速処理 | レアリティ、同時解決、盤面位置のどれで解決したか |

### 対策余地

| 指標 | 見る理由 |
|---|---|
| 対策行動の発動前に負けた回数 | 回答札が理論上だけで実戦に間に合っていない可能性 |
| 対策対象へ届いた回数 | 中後衛アクセス、範囲攻撃、低HPサーチが機能しているか |
| キーカード撃破ターン | エース保護に対して突破余地があるか |
| 最適候補/対策候補で結果が変わるか | カード入れ替え程度で現実的な回答があるか |
| 苦手対面の勝率 | 完全なじゃんけんではなく、ふんわり不利に留まっているか |

## 危険フラグ

| フラグ | 判断目安 |
|---|---|
| 非ゲーム化 | 主要対面で3T以内決着が多い |
| 対策不能 | 回答札を入れても勝率が大きく変わらない |
| 過剰汎用 | 複数の勝ち筋デッキに同じカードがほぼ必須になる |
| ミラー膠着 | それ自体は即問題にしない。環境がミラー一色になり、試合体験が停滞する場合のみ問題視 |
| 先手固定 | 同速/AG操作で同じ側だけが勝ちやすい |
| エース依存過多 | エースが倒れた瞬間にゲームが終わり、代替ルートがない |

## 甲殻菌糸の読み方

甲殻菌糸は、単体点の低い防御/回復カードが、タイタンミセリウムの行動回数を増やすことで実戦上の勝利に変換されている。

これは好ましい。カード単体採点では低く見えるカードに、デッキ構築上の居場所が生まれているためである。

今後見るべきなのは「甲殻菌糸にシナジー点を足すか」ではなく、以下である。

| 観点 | OK | NG |
|---|---|---|
| エース保護 | 守れば強いが、集中攻撃/貫通/防御低下で崩せる | 守った時点でほぼ勝ち |
| 決着速度 | 7〜10T程度で決着し、ログに変化がある | 20T以上の膠着が頻発する |
| 対策余地 | カード選定、配置、サーチ、範囲、毒耐性などで結果が動く | 対策してもほぼ同じ結果 |
| 構築報酬 | 防御役を入れる手番/コストの代償がある | 防御役が単体でも強く、入れ得になる |

## 運用

1. まずカード単体点で、明らかなコスト詐欺を避ける。
2. 勝ち筋ごとに、現プールで最適に近い候補デッキを複数組む。
3. 候補デッキ群を総当たりし、勝率、決着ターン、引き分け率を見る。
4. キーカードの行動回数、必殺技発動、状態異常、延命量をログから確認する。
5. 問題があれば、シナジー課税ではなく、効果要素、対象、持続、必要ターン、枚数制限を調整する。

この順序なら、構築で強くなる快感を残しながら、対策不能な定番コンボだけを抑えられる。
